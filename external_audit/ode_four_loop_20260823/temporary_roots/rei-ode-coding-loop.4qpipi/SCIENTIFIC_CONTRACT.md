# SCIENTIFIC AND SOFTWARE CONTRACT

## User-visible objective

Run the supplied coding harness as a research-only loop over prior mathematical, algorithmic, and coding ODE-remediation seeds, audit them against the current REI Bianchi implementation, select at most one smallest sufficient design, and produce an implementation-ready validation/rollback plan without changing the target repository.

## Current task layer

`diagnose → design`; `implement` is not authorized in this work unit.

## Preserved behavior and identities

- Exact target HEAD, tracked bytes, two existing untracked bundle paths, sealed/historical inputs, references, tolerances, conventions, schemas, and stage claim tiers.
- Existing behavior is characterized, not silently redefined; known false success is evidence, not a new baseline.
- Forensic reproduction and corrected-science authority remain non-interchangeable.

## Governing numerical contracts

- A claimed interval encloses the exact target under its declared arithmetic/domain.
- A solver/certificate success is consumable only after all required finite, domain, residual/enclosure, event/terminal, invariant/semantic, and diagnostic predicates pass.
- Algebraic stage error, local truncation/discrepancy, continuous defect, global trajectory error, QoI error, event-time error, data/interpolation error, and roundoff are distinct.
- Event detection/localization/restart is part of the hybrid method contract, not a warning string.
- Same-code parity, historical expected output, and green regression tests are not independent correctness evidence.

## Valid design regime

- Current active deterministic CPU NumPy/SciPy adaptive H/He thermochemistry chain and immutable upstream BDF-derived forcing ancestry.
- Smooth fixed branches and branch/table-event boundaries; every proposal states inconclusive/out-of-regime conditions.
- Stochastic, GPU, spatial PDE/CFL, symplectic/Hamiltonian, and unrelated surfaces are excluded.

## Required acceptance properties

- finite/schema/domain safety and no silent fallback;
- exact containment for declared interval/certificate operations;
- independent constraint/invariant/semantic admission;
- deterministic ordering and explicit state transitions;
- ambiguous all-root/event status fails closed;
- exact identity and bounded resources at process/file/package boundaries;
- compatibility preservation or explicit new-lane identity;
- complexity/scaling and dense/reference fallback stated.

## Reference and falsifier classes

Exact rational cancellation/linear-system witnesses; analytic/limiting/manufactured cases; independent high-precision or validated references; property/metamorphic/mutation/differential/state-machine/containment/resource tests; existing regression suite as compatibility-only evidence.

## Failure semantics

NaN/Inf, non-convergence, false enclosure, empty/partial result, clipped/coerced invalid value, missing expected event, unresolved multiple/grazing event, wrong terminal/resume transition, runtime/tool/input drift, containment failure, quota termination, or incomplete diagnostics cannot serialize or be consumed as success.

## Approval boundary

Stop before target code/test/doc changes, worktree implementation, dependency addition, baseline/tolerance/convention/schema change, production/history/parity/package/BDF execution, external write, push/merge/reseal, or scientific promotion.

## Completion bar

Frozen seeds and blocker universe audited; current code/version/evidence bound; at most three designs compared; one smallest sufficient design selected or no-selection justified; file-level execution/tests/rollback plan complete; independent design review non-inconclusive; harness and custody checks pass; no target change.
