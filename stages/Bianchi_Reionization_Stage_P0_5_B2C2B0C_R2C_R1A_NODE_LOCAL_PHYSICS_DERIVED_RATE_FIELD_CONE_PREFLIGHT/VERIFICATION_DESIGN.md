# Verification design

## Independent layers

1. **Source and definition audit:** trace the original capacity gate and its
   later promotion into R2B/R2C/R2C-R1 state coordinates.
2. **Exact algebra:** prove refinement covariance, H-generator positivity and
   conservation, the cumulative photon identity, and common-equilibrium
   extrapolation.
3. **All-row endpoint audit:** stream the complete logical node-state and
   node-group artifacts without subsampling.
4. **Macro reduction audit:** independently re-sum every locked mass, current,
   opacity, transfer, and current–Gamma moment.
5. **Farkas partition replay:** preserve all 497 certificate labels and test
   whether each constraint belongs to the corrected physical state space.
6. **Convex endpoint/cap counterexample:** verify every endpoint pair and the
   six mass-certificate pairs without invoking the production solver.
7. **Adversarial review:** separate blocker resolution from production-history
   authorization.
8. **Durability:** independent hashes, stage manifest, repository verifier,
   ZIP CRC, Git fsck, and an offline incremental bundle.

## Locked numerical gates

- state and sign failures: exactly zero;
- non-finite direct-rate rows: exactly zero;
- current–Gamma and inherited moment residuals: `<=5e-11`;
- endpoint/cap segment failures: exactly zero;
- all 497 certificate labels replayed;
- symbolic/high-precision fallback: pass;
- no clipping, node-wise free fit, dynamic KL repair, or inter-macro transfer.

## Non-authorizing diagnostics

The endpoint-local `N/dt+R` comparison, direct coefficient-derived reaction
rates, and affine endpoint segment do not define the production history. They
are used only to test classification, support, signs, and the logical scope of
the old no-go certificates.
