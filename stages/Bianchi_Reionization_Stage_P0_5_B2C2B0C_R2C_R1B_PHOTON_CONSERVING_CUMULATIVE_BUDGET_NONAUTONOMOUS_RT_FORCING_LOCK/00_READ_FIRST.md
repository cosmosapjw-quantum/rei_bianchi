# R2C-R1B — read first

This stage tests whether the currently durable endpoint and ledger data identify a photon-conserving, nonautonomous node/group radiation forcing and a genuine thermal history. It does **not** assume that a forcing exists merely because endpoint states are admissible.

Canonical inheritance:

- R2C-R1A state/flux/budget reclassification;
- R2A global reduced-DAE moments and exact photon ledger;
- R2B node and group endpoint lifts;
- no production promotion, clipping, inter-macro transport, source/fesc calibration, recombination surrogate, CAMB transfer, or Bianchi feedback.

The decisive distinction is between existence, identifiability from locked inputs, and numerical convergence of a specified operator. Failure of identifiability is an input/closure deficit, not an integrator failure.
