# Harness integration

The coding harness supplies the task contract, red/green tests, validation ladder, independent diff review and reproducibility closeout. The research harness supplies the hypothesis ledger, evidence acquisition, claim-source audit, adversarial alternatives, physics/dimensional checks and explicit stop rules.

For this stage these are enforced as follows:

1. The present pre-calculation lock is committed before rate derivation.
2. Rate interval derivation is a separate artifact and commit before feasibility results are inspected.
3. Production code is test-first; failed attempts are retained under `state/ATTEMPT_*`.
4. Scientific, numerical, exact-symbolic, independent-output and repository validations are separate receipts.
5. The result is either an all-lane authorization or a fail-closed dual certificate. No diagnostic path is silently upgraded.
