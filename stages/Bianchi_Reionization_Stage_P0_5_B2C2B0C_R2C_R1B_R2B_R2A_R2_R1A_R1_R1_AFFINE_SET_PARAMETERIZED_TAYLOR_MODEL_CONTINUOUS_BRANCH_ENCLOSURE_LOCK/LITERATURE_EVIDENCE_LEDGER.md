# Literature evidence ledger

1. Neher, Jackson & Nedialkov, *On Taylor model based integration of ODEs* — Taylor models retain polynomial dependence and reduce interval dependency/wrapping relative to plain boxes.
2. Houska, Villanueva & Chachuat, *A validated integration algorithm for nonlinear ODEs using Taylor models and ellipsoidal calculus* — affine set-parameterization and ellipsoidal remainders provide a stable validated-flow architecture.
3. Perić, Villanueva & Chachuat, *Set-valued integration of nonlinear differential equations with parametric uncertainties* — polynomial-model inclusions propagate parameter-dependent trajectories and sensitivities.

These sources motivate the next sparse local-generator architecture.  They do not supply the project-specific H/He branch kernel or certify the present numerical result by themselves.
