# Independent adversarial review

## Steelman

The stage makes the actual four evaluation sites explicit without changing the
primal map, certifies every frozen-state H/He population block and scalar thermal
root across all three lanes, preserves exact invariants, and reproduces the
known schedule counterexample. This is strong evidence that the remaining task
is a tractable representation problem rather than a hidden local singularity.

## Strongest objection

All successful certificates condition on a frozen material/forcing context.
The production claim concerns a nonlinear composition in which population,
temperature, owner normalization and branch cell feed back between sites. No
outward remainder encloses those interactions. The stage therefore cannot
support a continuous-family or public-width claim.
