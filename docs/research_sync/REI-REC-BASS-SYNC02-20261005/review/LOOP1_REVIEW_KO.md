# Loop1 독립 판정

후보 생성·검증 설계에 참여하지 않은 `/root/sync_independent_review`가 세 후보를 **범위 한정 PROMOTE**로 판정했다. 미해결 blocking finding은 없다.

| 후보 | 판정 근거 | 허용되는 다음 단계 |
|---|---|---|
| REI-PB03 | 실제 REC 공개 API를 호출하는 별도 consumer, 10 native tests; collapsed/retained source와 같은-rate closure defect 구분; 별도 Decimal70 72 valid/8 invalid cases, 2170 checks | 지정된 pure-H 한 온도 배경의 독립 trajectory 검증 |
| BASS-REI-CLOCK01 | 30 scoped tests, Decimal70 151 cases/5001 checks, 기존 적분기 재사용 | 같은 frozen opacity cell을 세 시간좌표에서 비교 |
| HE-FLRW02B native | 공급 ZIP/제안 test bytes 일치, 실제 REI의 2 tests/274 비교 통과 | finite mixed native gate 완료 결과를 공급자에게 반환 |

REC/REI 61 source 파일, BASS baseline 21 파일의 고정 identity를 대조했다. HE raw log의 274 비교를 재파싱하여 기존 tolerance로 확인했다. reviewer는 전체 native suite를 재실행하지 않았다.

Peebles 첫 9 PASS/1 FAIL은 decimal literal과 실제 f64 입력 산술의 1 ULP 차이였다. 원 실패를 보존하고 동일 입력의 정확 산술식으로 테스트 기대값을 수정한 뒤 10 PASS를 확인했다. 물리식·원천·과학 tolerance 변경은 없다. BASS tree metadata의 commit/tree 혼동도 coordinator가 실제 Git commit으로 정정했다.

이 판정은 full BASS build, retained n=2 이력, EoR/관측 예측, continuum enclosure, finite-T/스펙트럼 승인, HE owner ACK를 의미하지 않는다. HE 결과는 반환 준비 완료이며 ACK를 새로 만들지 않았다. Clock의 매우 작은 survival/probability underflow는 고정 absolute criterion으로 평가했으므로 전역 상대오차 보장으로 확대하지 않는다. 다음 loop는 별도 사전등록과 실제 통합 결과에 대해 판단한다.
