# Retired Python research source

These files are the exact former `src/rei_bianchi/` source tree and Python
packaging/bootstrap inputs. They are retained for historical scientific
provenance and are not the active development or execution path. The Git move
preserves each source blob; no physical claim is transferred to the Rust crate.

The scoped Rust implementation is `rust/rei_microphysics`. It ports seven pinned
functions only. The rest of the former Python/JAX solver is unavailable in this
checkout and has no Rust replacement yet. The frozen source subset, raw parity
failure and current scientific state remain under their existing paths.
