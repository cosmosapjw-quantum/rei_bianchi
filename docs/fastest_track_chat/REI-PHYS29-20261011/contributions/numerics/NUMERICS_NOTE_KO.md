## 3. 기존 δ=.05 한 폭의 진단

δ는 **반폭0.05eV**다. PHYS27의 이미 저장된 두 근과 PHYS28의 전체 직렬화 선형 이동·잔차를 그대로 소비했다. 예측에는 기존 선형 이동에 새 dδ²를 더했다. 새로 산출한 c와 PHYS28 c의 차이는 각각 -7E-79, -1E-79eV로 기록되며, c를 기존 값으로 바꿔 계산한 d도 사전 기준으로 교차 점검했다. 이 finite precision 혼합은 명시된 입력 선택이며 근 보정이 아니다.

## 4. 검증의 실제 범위

네 에너지 a,v*,u0,b에서만 각 경로를 한 번 평가했다. 기본 경로는 실제 PHYS28 순수 코드를 읽어 확장한 degree4 log Taylor Jet이고, 보조 경로는 독립적으로 표현한 logσ의 네 번째 도함수와 Bell 다항식이다. k″에서 정규화 K를 포함한 K E⁻²(D⁴+2D³−3D²)φ를 사용했다. k,k′,k″,sigma의 최대 scaled 차이는 **3.69360000000e-76**, 사전 허용치는10⁻⁶⁰이었다.

응답의 편미분과 c,d에도 서로 다른 후처리를 사용했다. Jet 값에는 명시적 확률·위치 chain rule을, scalar 값에는 δ와 W−w의 이변수2차 계수 대수를 적용했다. 두 번째 경로는 첫 경로의 편미분이나 근 계수 함수를 호출하지 않는다. A,B,C,Fδδ,FδW,FWW,c,d의 최대 scaled 차이는 **1.73210400000e-75**였다. fit,source 상수,J,Decimal 함수,지정된 분포족은 공유하므로 독립 물리 자료로 부르지 않는다.

분모를 버리지 않은 일반 응답, 비정규화 분자 항등식의 A 보정, dV=1/3, 가중 평균 k″, 각 항의 합, δ와 δ² root coefficient 소거, 질량1·평균m·실제 분산W의 여섯 이변수 계수를 확인했다. 과거 PHYS28의 k,k′,B,C,c 및 응답 원기록과 비교했지만 과거 프로그램은 실행하지 않았다.

정확한 Fraction 시험함수 ktoy(E)=(E−m)²−w는 이 물리 kernel의 추가 평가가 아니다. 질량·평균·분산으로부터 정확히 Atoy(δ,W)=W−w가 되어 양 경계에서 C=1, 나머지 폭 편미분과 c=d=0이다. 두 새 구현에서 이를 **정확한 유리수 등호**로 확인했고, daverage=−1/3와 dV=+1/3도 정확히 상쇄됐다. 엄격 k‴<0를 이 quadratic toy에 적용하지 않는다.
