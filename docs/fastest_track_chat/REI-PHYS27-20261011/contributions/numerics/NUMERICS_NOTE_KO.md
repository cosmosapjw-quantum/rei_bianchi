## 2. 원식과 정규화 추적

\[

\quad x=E/E_0,\quad z=\sqrt{x/y_a},\quad r=p/2-11/2.
\]

\(E_0,y_a,p,\sigma_0,c_{\rm area},\chi\)는 source binary64 리터럴의 정확 실수 해석을 사용한다. 에너지 지원구간은 HI cutoff 13.60 eV와 HeI cutoff 24.59 eV 사이에 있으므로 식의 threshold 분기를 넘지 않는다. 결합에너지 \(\chi={\rm f64}(13.598434599702)\) eV는 opacity cutoff와 구별한다. N0는 \({\rm f64}(0.05)\) photon/H, 빛의 속도는 source cgs 값 29979245800 cm/s다.

\[
\kappa=c n_H(1-x_{HII}),\quad q=2\,\mathrm{shear}^2,
\quad f(E)=\sigma(E)[J_x+J_w(E-\chi)],
\]

\[
\boxed{k(E)=\frac{qN_0\kappa}{180}\{D^2f+3Df\}},
\qquad D=E\partial_E.
\]

분모 180은 \(g\)의 1/4와 \(qN_0/45\)를 결합한 것이다. 두 인자를 다시 곱하지 않는다. \([k]={\rm s}^{-4}\)이며 \(\epsilon^2t^4\)의 초기 HeIII 계수다. Metric (-+++), gas-comoving proper seconds, \(w\) in eV/H, 시간 추가 factorial 없음이라는 계약을 유지한다. \(J_x,J_w\)는 `PHYS22_INITIAL_COEFFICIENTS.json`의 `results.baseline_local.J_nonphoto[2][0]`, `[2][3]` 전체 직렬화 소수다. 각각 약 \(-6.01326833811\times10^{-17}\), \(+2.52759476962\times10^{-18}\)다.

주 경로는 \(D^n f/n!\), \(n=0,\ldots,3\)의 jet으로 k와 k′를 동시에 얻는다. 별도 scalar 경로는 원 단면적의 로그 도함수

\[
\ell_1=\frac{2x}{x-1}+r-\frac{pz}{2(1+z)},
\qquad
\ell_2=-\frac{2x}{(x-1)^2}-\frac{pz}{4(1+z)^2},
\]

\[
\ell_3=\frac{2x(x+1)}{(x-1)^3}-\frac{pz(1-z)}{8(1+z)^3}

## 3. 평균화 적분의 검토

\[
\bar k_\delta(c)=\frac12\int_{-1}^1 k(c+\delta x)\,dx
\]

에 주 Gauss–Legendre 16점 규칙을 적용했다. 24점 규칙은 사전에 정한 7개 중심에서만 비교했다. 16점·24점의 양의 Legendre 근 8개·12개를 Decimal Newton으로 구하고 부호를 반사했다. binary64 cosine은 시작 추정값으로만 쓰며 최종 노드·가중치는 Decimal의 polynomial recurrence로 계산한다. 실제 노드 근 풀이는 20개, Newton 반복 합계는 118회다. 이들은 물리적 응답 영점 두 개와 분리해 계수했다.

각 규칙의 모든 다항식 차수 \(d=0,\ldots,2n-1\)에서

\[
\sum_iw_ix_i^d=
\begin{cases}2/(d+1),&d\text{ even},\\0,&d\text{ odd}\end{cases}
\]

를 수치 확인하고, 모든 가중치의 양수성, 노드의 중복 없음과 (-1,1) 지원을 확인했다. 가중치 합 검사는 d=0을 포함한다. 최대 정규화 오차는 16점에서 약 \(5.0\times10^{-80}\), 24점에서 약 \(1.0\times10^{-79}\)였고 사전 허용오차는 \(10^{-60}\)이었다. 이는 수치 노드와 규칙의 구현 검산이다.

별도 적분 경로는 각 중심의 129점 균일 격자에서 위 scalar k·k′를 계산하고 32·64·128 panel의 composite Simpson 평균을 얻는다. 평균값의 Simpson 계수는 \(1/(3n)\)이다. 원 Simpson 값의 오차는 모든 중심과 두 함수에서 세 단계에 걸쳐 엄격하게 감소했다. 다시

\[
R^{(6)}_{64}=\frac{16S_{64}-S_{32}}{15},\qquad
R^{(6)}_{128}=\frac{16S_{128}-S_{64}}{15},
\]

\[
R^{(8)}=\frac{64R^{(6)}_{128}-R^{(6)}_{64}}{63}
\]

를 구성했다. kbar의 scale은 \(10^{-64}\ {\rm s}^{-4}\), kbar′의 scale은 \(10^{-64}/18\ {\rm s}^{-4}{\rm eV}^{-1}\)이며 두 함수의 최대값을 합쳐 다음과 같다.

| 실제 비교 | 최대 정규화 차이 | 사전 허용오차 |
|---|---:|---:|
| GL16 대 GL24 | \(4.50\times10^{-78}\) | \(10^{-55}\) |
| GL16 대 별도 scalar Simpson \(R^{(8)}\) | \(1.05046\times10^{-28}\) | \(10^{-22}\) |

7개 비교 중심의 선택 규칙은 \(a_\delta,m,b_\delta\), 두 새 근의 이동 중심, 실제 \(W=19.74\)에서 두 경계의 이동 중심이다. 근의 값은 실행 후 결정되지만 선택 규칙 자체는 실행 전에 고정했으며 추가 중심은 없었다. 이 비교는 적분 정확도의 강한 수치 근거다. directed rounding·해석적 적분 잔차 상계를 사용한 엄밀 인증은 아니다.
