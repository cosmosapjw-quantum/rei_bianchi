# PHYS26 평균·분산 고정 응답: 제한 수치 검산 기록

이 기여는 고정된 두 선 후보와 이차 보간식의 구현을 검사했다. 새 독립 실행 프로그램의 첫 실행에서 **281/281 검사 통과, 실패 0, exit 0**을 얻었다. 전역 상·하한과 전 분산 부호 정리는 별도 연속구간 증명이 담당한다. 이 기록의 증거 등급은 **numerically checked / implementation-verified**이며, 최종 판정자는 아니다.

## 1. 실제 사용한 입력과 역할

PHYS26 계약 SHA256 `d4ff7556332f75447d93e0c6a8da4a0d96cb8a86b257f111809d388b7f2b80ce`와 active handoff를 읽었다. J 입력 SHA256 `6c7a4f239ef48c2a7c60592fc048600317f1233f3028434ebd1b3c7e55682a79`의 `results.baseline_local.J_nonphoto[2][0]`, `[2][3]`에 저장된 소수 문자열을 그대로 소비했다. 그 값은 각각 약 \(-6.0132683381109739\times10^{-17}\), \(2.5275947696163279\times10^{-18}\)이다. 직렬화 소수를 정확한 수학 상수로 해석하며 J의 물리적·수치적 불확실성을 새로 둘러싸지 않는다.

PHYS25 helper의 실제 순수 계산부를 읽고, source literal 해석, 거듭제곱 함수, Taylor jet 대수, 원 적합식의 부분을 새 코드에 명시적으로 적응했다. 기존 degree 5 jet을 **degree 3**으로 줄였다. 기존 module import, main, 근 탐색, 유한차분 검산, 닫힌 suite를 실행하지 않았다. `atomic_provider.rs`의 HI 적합식과 threshold 분기, PHYS25 원 결과의 두 root record와 variance/response record도 읽었다. 이 입력들의 정확한 경로·크기·해시는 사전 freeze와 provenance에 있다.

이 기여자는 full history와 PHYS25 결과, PHYS26의 두 선 후보를 받았으므로 **NONBLIND**다. 새 PHYS26 theory 결과나 다른 기여는 프로토콜 설계 및 첫 실행 전에 읽지 않았다. 별도 표현의 검산은 계산 경로의 차이를 제공한다. 그 사실을 사람·입력·원자 자료의 독립성과 동일시하지 않는다.

## 3. 원식의 서로 다른 두 계산 경로

고정 에너지 구간은 \([a,b]=[13.61,24.58]\) eV, 평균은 \(m=18\) eV다. \(D=E\partial_E\)로 두고

\[
f(E)=\sigma(E)[J_x+J_w(E-\chi)],\qquad
F=\frac{qN_0\kappa}{180},
\]

\[
k(E)=F(D^2f+3Df),\qquad
k'(E)=\frac{F}{E}(D^3f+3D^2f).
\]

따라서 \(k\)는 이미 \(qN_0/45\) 정규화를 포함하며 단위는 s\(^{-4}\)다. \(k'\)의 단위는 s\(^{-4}\) eV\(^{-1}\)다. source binary64 리터럴은 정확한 실수 값으로 해석한다. 이는 native 연산별 반올림을 재현한다는 뜻이 아니다.

첫 경로는 \(E(t)=Ee^t\)에 대한 원 적합식의 Taylor 계수 \(D^nf/n!\), \(n\le3\)를 구성한다. 둘째 경로는 Taylor jet을 사용하지 않고, 원 단면적과 그 로그미분을 scalar 식으로 계산한다. \(x=E/E_0\), \(z=\sqrt{x/y_a}\), \(r=p/2-5.5\)라 쓰면

\[
\sigma=\sigma_0(x-1)^2x^r(1+z)^{-p}\,10^{-18},
\]

\[
\ell_1=D\log\sigma=\frac{2x}{x-1}+r-\frac{pz}{2(1+z)},
\]

\[
\ell_2=D^2\log\sigma=-\frac{2x}{(x-1)^2}-\frac{pz}{4(1+z)^2},
\]

\[
\ell_3=D^3\log\sigma=\frac{2x(x+1)}{(x-1)^3}
-\frac{pz(1-z)}{8(1+z)^3}.
\]

\(h=J_x+J_w(E-\chi)\), \(t=J_wE\), \(s_2=\ell_1^2+\ell_2\), \(s_3=\ell_1^3+3\ell_1\ell_2+\ell_3\)로 두면 별도 경로는

\[
k=F\sigma\{(s_2+3\ell_1)h+(2\ell_1+4)t\},
\]

\[
k'=\frac{F\sigma}{E}\{(s_3+3s_2)h+(3s_2+9\ell_1+4)t\}
\]

를 계산한다. 이는 곱미분으로 직접 얻은 식이며 \(k''\)나 \(k'''\)의 새 계산·부호 검사를 하지 않는다.

비교점은 정확한 \(a,m,b\)와 PHYS25에 저장된 \(v_*\), \(u_0\)의 유한 소수 5개다. Decimal precision은 160으로 고정했다. \(k\)는 \(10^{-64}\) s\(^{-4}\), \(k'\)는 \(10^{-64}/E\) s\(^{-4}\) eV\(^{-1}\), \(\sigma\)는 \(10^{-18}\) cm²로 각각 정규화한 오차를 기록했다. 15개 비교의 최대 scaled 차이는 **\(3.9469\times10^{-157}\)**이며 사전 허용치는 \(10^{-120}\)이다. 이 값은 정해진 표현과 정밀도에서의 구현 일치 정도다. 물리적 정확도, J 불확실성 또는 rigorous interval 오차를 뜻하지 않는다.

## 4. 모멘트·접촉·기대값의 검사

\(L=m-a=4.39\), \(H=b-m=6.58\)에서 후보 접촉점은

\[
v=m+W/L,\qquad u=m-W/H.
\]

각 \(W\)에 대해 handoff의 \(P_W^a\), \(P_W^b\)를 만들고 질량, 평균, 분산, 이차 모멘트, 광자 수와 총 광자 에너지를 검사했다. 양의 질량을 가진 지지가 허용 구간 안에 있는지도 확인했다. \(W=0\)에서는 두 후보 모두 양의 질량 지지가 \(\{m\}\), \(W=W_{\max}\)에서는 \(\{a,b\}\)이며 응답이 일치했다.

이차식은 접촉 중심 \(c\)에서 \(Q(E)=c_0+c_1(E-c)+c_2(E-c)^2\)로 구현했다. \(Q_a\)는 \(a\)의 값과 \(v\)의 값·기울기를, \(Q_b\)는 \(b\)의 값과 \(u\)의 값·기울기를 맞춘다. 모멘트로 계산한

\[
\int Q\,dP=c_0+c_1(m-c)+c_2[W+(m-c)^2]
\]

와 두 후보 law의 명시적 합을 각각 비교하고, 해당 접촉 law의 \(\int k\,dP\)와 일치하는지 확인했다. 접촉을 식으로 구성한 뒤 검사하는 부분은 대수 구현 검사다. 이 검사만으로 커널의 전역 형태가 독립 검증되었다고 주장하지 않는다.

각 분산에서 \(a,m,b\)에 한하여 \(Q_a-k\), \(k-Q_b\)의 비음수 잔차를 검사했다. 허용치는 \(10^{-120}\times10^{-64}\) s\(^{-4}\)다. **42개의 표본 통과는 연속구간 dual 부등식의 증명이 아니다.** 전역 부등식과 유일성은 별도 수학 기여의 대상이다.

## 6. 같은 평균·분산의 실제 혼합 예시

\(W=19.74\) eV²에서 두 후보는

\[
A(P^b)\simeq-2.7648705362417584\times10^{-65},\qquad
A(P^a)\simeq+1.6203272268660677\times10^{-65}
\]

의 반대 부호를 가진다. \(P_\alpha=\alpha P^a+(1-\alpha)P^b\)를 구성하면 같은 질량·평균·분산을 유지한다. \(\alpha=1/4\)일 때 실제 응답은 약 \(-1.6685710954648019\times10^{-65}\) s\(^{-4}\)이고 선형 결합 응답과 일치했다.

별도 root 탐색 없이 두 계산 응답으로

\[
\widehat\alpha_0=\frac{-A(P^b)}{A(P^a)-A(P^b)}
\simeq0.63050076315880260625
\]

를 계산했다. 이 유한 Decimal 혼합의 직접 합 응답은 \(10^{-224}\) s\(^{-4}\), 선형식으로 계산한 응답은 반올림상 \(0\times10^{-224}\)였다. 두 값을 원 결과에 모두 보존했다. 네 선의 근사 질량은 에너지 순으로 다음과 같다.

| 에너지, eV | 확률 질량 |
|---:|---:|
| 13.61 | 0.319031404737370289 |
| 15 | 0.253789663717649149 |
| 22.4965831435079727 | 0.311469358421432317 |
| 24.58 | 0.115709573123548244 |

정확한 커널 값으로 같은 혼합계수를 정의했을 때의 대수적 영 응답과 유한 소수 계산 잔차를 혼동하지 않는다. 이 구성은 한 가능한 혼합 예시이며 모든 중간 응답 law의 유일성이나 최소 지지 선 수를 주장하지 않는다.
