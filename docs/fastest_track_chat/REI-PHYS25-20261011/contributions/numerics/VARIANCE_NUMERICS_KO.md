# PHYS25: HeIII 비음수 응답을 위한 분산 후보의 제한 수치 계산

## 1. 결과와 근거 상태

평균 광자 에너지 \(m=18\) eV, 지지구간 \(I=[a,b]=[13.61,24.58]\) eV, 고정 광자 수·초기 기체·직렬화 수치 \(J\)에 대해, PHYS24의 아래끝점 고정 두 선 경로에서 영 응답을 주는 새 근을 계산했다. 이 기여의 근거 상태는 **numerically checked / implementation-verified**다. 아래 수치 자체는 전역 최적성 증명이 아니며, 별도 연속구간 부호 인증과 변분 논증을 함께 사용해야 최적해로 해석할 수 있다.

\[
P_v=\frac{v-m}{v-a}\delta_a+\frac{m-a}{v-a}\delta_v,\qquad
F(v)=(v-m)k(a)+(m-a)k(v).
\]

정확한 후보는 \(F(v_*)=0\)으로 정의된다. 이 근의 존재와 경로 내 유일성은 PHYS24의 고정 모멘트 응답 결과를 입력으로 소비한다. 이번 새 수치 근삿값은 다음과 같다.

| 양 | 수치 근삿값 |
|---|---:|
| 위쪽 선 \(v_*\) | \(21.7220830648268126070863655411\) eV |
| 아래쪽 선 확률 \(p_a\) | \(0.4588319714039166486270728472\) |
| 위쪽 선 확률 \(p_v\) | \(0.5411680285960833513729271528\) |
| 후보 분산 \((m-a)(v_*-m)\) | \(16.3399446545897073451091447255\) eV\(^2\) |
| 후보 RMS 폭 | \(4.0422697404539577985836080106\) eV |

이 수치 계산은 원래 기체 Jacobian이나 원자 모형의 불확실성을 둘러싸지 않는다. 높은 Decimal 정밀도는 고정된 수학적 입력의 계산 정밀도다.

## 2. 정의·단위·정규화

PHYS24와 같은 광자 수 정규화 \(dP=d\nu_0/N_0\)를 사용한다. \(N_0\)는 소스 binary64 리터럴 0.05의 정확한 실수 해석이다. \(P\)는 에너지 가중 확률분포가 아니라 광자 수 기준 확률분포다.

\[
\int dP=1,\quad \int E\,dP=m,\quad
V(P)=\int(E-m)^2dP,\quad A(P)=\int k(E)dP.
\]

\(V\)의 단위는 eV\(^2\), \(A\)의 단위는 s\(^{-4}\)다. 커널 \(k\)에는 이미 \(qN_0/45\)가 포함돼 있으므로 추가 정규화 인자를 곱하지 않았다. Metric은 \((-+++)\), 시간은 기체 동행 proper seconds, 에너지는 eV다. \([\epsilon^2]\)는 두 번째 \(\epsilon\) 미분의 절반이며, 시간 계수에 추가 factorial을 넣지 않는다.

수치 함수는 HI-only 분석 구간에서 원래 단면적 식을 사용한다. 원자 임계에너지 \(\chi=\mathrm{f64}(13.598434599702)\) eV와 opacity cutoff \(\mathrm{f64}(13.60)\) eV를 구별했다. 빛의 속도는 소스 cgs 리터럴로 유지했으며 natural units로 치환하지 않았다.

입력 \(J\)는 **inputs/PHYS22_INITIAL_COEFFICIENTS.json**의 \(J_{\rm nonphoto}[2][0]\), \(J_{\rm nonphoto}[2][3]\)다. SHA256은 **6c7a4f239ef48c2a7c60592fc048600317f1233f3028434ebd1b3c7e55682a79**다.

## 3. 새 계산 방법과 사전 고정

**PROTOCOL.json**을 2026-10-10 22:10:29.216169 UTC에 고정했다. SHA256은 **5b5c16a41bdbc0136a456ebc99697e6eb0da053532b683c862ed75a300d792d3**다. 다른 PHYS25 기여자의 새 도함수·변분·근 결과를 읽기 전에 방법, 정밀도, 표본, 반복 예산, 허용오차를 고정했다.

PHYS24의 원식 Taylor-jet 구현을 명시적으로 복사·확장하여 별도의 **variance_candidate.py**를 작성했다. 기존 프로그램을 import하거나 기존 main을 호출하지 않았다. 기존의 로그 에너지 4차 jet를 5차까지 확장했다. \(D=E\partial_E\), \(f(E)=\sigma(E)[J_x+J_w(E-\chi)]\), \(C_0=qN_0\kappa/180\)으로 두면

\[
\begin{aligned}
k&=C_0(D^2+3D)f,\\
k'&=\frac{C_0}{E}(D^3+3D^2)f,\\
k''&=\frac{C_0}{E^2}(D^4+2D^3-3D^2)f,\\
k'''&=\frac{C_0}{E^3}(D^5-7D^3+6D^2)f.
\end{aligned}
\]

마지막 식은 바로 앞 식에 \(E^{-1}D\)를 적용해 얻는다. 로그 미분과 에너지 미분의 변환에서 \(E^{-2}\)를 미분하는 항을 포함했다.

세 근 계산은 각각 **240회의 이분법**으로 제한했다.

1. 아래 선 \(a=13.61\) eV를 고정한 주 후보의 \(v\).
2. 위 선 \(b=24.58\) eV를 고정한 비교 후보의 아래 선 \(u\).
3. 아래 선 14 eV를 고정한 비교 후보의 \(v\).

기본 산술·모멘트 항등식 허용오차는 \(10^{-125}\), 응답 영점 허용오차는 끝점 응답 크기로 정규화한 \(10^{-65}\), 수치 bracket 폭 기준은 \(10^{-70}\) eV다. 접촉·slack 산술의 절대 허용오차는 \(10^{-60}\) eV\(^2\)다. 이 기준은 실행 후 바꾸지 않았다.

독립적인 원식 평가 경로는 \(E\exp(jh)\), \(j=-6,\ldots,6\)의 13점 로그 차분이다. 도함수 1–5차의 계수는 13차원 다항식 모멘트 방정식에서 정확한 유리수로 풀었다. \(h=10^{-5}\), \(h/2\)를 쓰고, 5차 로그 미분의 선도 \(h^8\) 오차를 없애는 Richardson 인자 256을 적용했다. 평가 중심은 사전 고정한 13.61, 14, 16, 18, 20, 23, 24.58 eV의 일곱 점이다. 중심이 지지구간의 끝점인 경우도 모든 차분 노드가 원식의 분석 HI-only 구간 안에 남음을 확인했다.

두 경로는 같은 물리식과 고정 상수를 사용한다. 따라서 이 검산은 미분 구현의 교차검사이며, 독립 원자 모형이나 독립 기체 Jacobian의 검증으로 해석하지 않는다.

## 4. 유한 근삿값과 실제 영 응답 후보의 구별

주 후보의 최종 수치 bracket 폭은

\[
3.7241480211674854611\times10^{-72}\ {\rm eV}
\]

이며, 원 데이터에는 160자리 연산으로 평가한 양 끝점과 부호를 모두 보존했다. 중점에서의 응답은

\[
A(P_{\rm midpoint})=-2.27486876683597\times10^{-137}\ {\rm s}^{-4}
\]

다. 이것은 유한 반복의 중점 잔차다. 작다는 이유로 이 유한 중점 측도가 정확히 \(A\ge0\)라고 주장하지 않는다. **정확한 후보는 근으로 정의한 \(P_{v_*}\)**이고, 표시한 유한 중점은 그 근사치다.

저장된 위 bracket 끝점에서는 \(F(v_{\rm hi})>0\)였으며, 이를 새 함수 평가 없이 확률·분산으로 번역한 기록을 **NUMERICAL_FEASIBLE_ENDPOINT.json**에 추가했다. 원 결과는 변경하지 않았다.

\[
A(P_{v_{\rm hi}})=+1.88107057989371\times10^{-137}\ {\rm s}^{-4}.
\]

이 별도 기록은 이미 저장된 endpoint 값의 산술 변환이며 새 커널 평가 0회·새 근 반복 0회다. 이것도 interval arithmetic에 의한 정확한 부호 인증은 아니므로 **수치적으로 feasible한 끝점**이라고만 부른다. 최종 root bracket 소수를 물리적 불확실성 경계나 엄밀 interval enclosure로 표시하지 않는다.

## 5. 접촉 dual 후보

\[
Q(E)=(E-m)^2-\lambda_0-\lambda_1(E-m)-\lambda_2 k(E)
\]

가 \(Q(a)=Q(v)=Q'(v)=0\)을 만족하도록 계수를 계산했다. \(h=v-a\), \(r=v-m\)라 두면

\[
\lambda_2=\frac{h^2}{k(a)-k(v)+h k'(v)},\quad
\lambda_1=2r-\lambda_2k'(v),\quad
\lambda_0=-r^2+\lambda_2[rk'(v)-k(v)].
\]

분모는 PHYS24의 엄격 볼록성과 연결되는 접선 차이다. 여기서는 실제 수치 양수도 확인했다.

| 접촉 계수 | 수치 근삿값 |
|---|---:|
| \(\lambda_0\) | \(16.3399446545897073451091447255\) eV\(^2\) |
| \(\lambda_1\) | \(8.0506477449576575544319670668\) eV |
| \(\lambda_2\) | \(1.9669451896344864853371736569\times10^{65}\) eV\(^2\)s\(^4\) |
| \(k/(10^{-64}\ {\rm s}^{-4})\)에 곱하는 계수 | \(19.6694518963448648533717365694\) eV\(^2\) |

세 접촉 방정식과 \(\lambda_2>0\), \(Q'(a)>0\), \(Q''(v)>0\)를 검사했다. 수치 후보 분산과 접촉 \(\lambda_0\)의 차이는 약 \(-4.47454\times10^{-72}\) eV\(^2\)였다. 이 극미한 음의 차이는 유한 중점이 약한 음의 응답을 갖는 것과 일관되며, 그 중점을 엄밀 feasible 측도로 판정하지 않은 이유이기도 하다.

고정한 7개 에너지와 접촉 부근 \(v-0.1,v,v+0.1\) eV의 총 10개 점에서 slack이 허용오차 내 비음수임을 확인했다. 예를 들어 \(Q(18)\simeq7.06429129147\) eV\(^2\), \(Q(24.58)\simeq6.31621204450\) eV\(^2\)였다. 이 표본 확인만으로 전 구간 \(Q\ge0\)을 증명하지 않는다.

첫 수치 실행이 끝난 뒤 root가 전한 요약에서는 별도 도함수 기여의 \(k'''<0\) 연속구간 인증과 변분 기여의 정확한 접촉 잔차 논증이 보고되었다. 이 새 요약은 방법 설계나 첫 실행에 사용하지 않았으며, 여기서는 그 원 증거를 재실행하거나 대신 판정하지 않는다. 이 기여의 수치가 전역 해와 연결되는 근거는 통합 보고서가 지정하는 별도 증명 파일이다.

다음은 전역 탐색이 아니라 사전 선택한 비교 측도들이다. “영 응답”의 수치는 근 잔차 허용오차 안에서의 값이며 정확한 비교 측도는 대응하는 영점으로 정의한다.
