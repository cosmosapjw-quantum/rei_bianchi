# C2Y external step controller
For accepted full-vs-two-half external metric e<target, use du_next=du clamp(0.9 (0.5 target/e)^(1/3),0.5,1.25), bounded to [1e-10,max_du]. At zero e, use factor 1.25. Rejected trial halves the step, leaving accepted state unchanged. This is a proportional heuristic with cubic local-order model, not an order proof for the mixed gas metric. The original external_trial acceptance and immutable energy budget are unchanged; controller source identity is added to compiled_identity. Prior V8 checkpoints require their original compiled source; no cross-version migration.
