## Geometry and units requiring explicit binding

Current native `bianchi_i.rs::AxisymmetricPoint` fixes transverse `a exp(-b)`, longitudinal `a exp(2b)`, signed `s=dot b`, directional Hubble `H-s,H-s,H+2s`. BASS PR163/164 uses this convention, while public `Sigma=sqrt(3)*abs(s)/H` loses sign. HE21's standalone factor is `g=exp(-dx)*sqrt[(1-mu_birth^2)exp(-2q dx)+mu_birth^2 exp(4q dx)]`; identifying its q directly with native s/H would reverse the native constant-shear sign. Reuse requires a stated convention transform; no claim of a code defect is made from labels alone. HE20 executable uses native geometry directly, despite its inconsistent README sentence.

All thermal binding must preserve native physical ionization energies separately from Verner cross-section support values. Native rates use proper cm^-3 and proper seconds, gas w is erg/H, finite photon stocks are per H, and the photo interface heat field is erg per absorber per second. A bolometric RR escape ledger alone does not specify a recombination photon spectrum, source age, direction or Case-B retransport closure.
