- PyDiatomic upstream https://github.com/stggh/PyDiatomic was read: it provides Johnson renormalized Numerov coupled-channel bound/photodissociation machinery. It is a reusable solver, not a source of the missing R9 channel potentials or couplings. No code was installed.
- MOLSCAT/BOUND/FIELD upstream https://github.com/molscat/molscat and https://github.com/molscat/molscat/releases were read; current releases page lists v2025.0. MOLSCAT is non-reactive coupled-channel scattering; BOUND solves corresponding bound-state problems. Neither turns an elastic S-matrix into an association/chemical rate. No build was performed.
- PySCF official FCI interface https://pyscf.org/user/ci.html and https://pyscf.org/quickstart.html supplies reusable finite-orbital electronic solvers and transition-RDM tools. An FCI label alone does not certify basis completeness or continuum normalization.
- Official PRIMAT https://www2.iap.fr/users/pitrou/primat.htm and https://primat.readthedocs.io/en/stable/howto/rate-variation-mc.html expose native rate/lifetime-prior propagation and sample covariance. These permit a prior-conditioned calculation even before any owner-specific observation likelihood is defined. Native prior covariance must not be called an observational posterior or an EFT truncation-error fit.
