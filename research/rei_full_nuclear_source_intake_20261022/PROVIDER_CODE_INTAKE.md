The NIST isotope table also lists Li6 absorption 940(4) b at 2200 m/s, but it is an absorption total and should not silently become Li6(n,t)He4 without a channel-resolved evaluation. `ENDF-301.pdf` contains a specific Li6(n,t) section and energy-dependent evaluation; retrieve that section if Li6 closure is implemented. The same JENDL tables report a 300 K thermal point, not a temperature grid valid over 100–10000 K. Under 1/v, `<σv>` is constant for an explicitly thermalized neutron ensemble; DDn produces ~2.45 MeV neutrons, so its secondary conversion needs slowing/transport or its own energy-dependent σ(E). DDp tritons are energetic too. The inherited external UV 5–60 eV lies below MeV photodisintegration thresholds, making *that spectrum's* forward photonuclear integrals exactly zero; it does not validate reverse capture coefficients or a Planck detailed-balance inverse. Avoid duplicate forward/inverse event terms.

Implementation handoff: represent each reaction with stoichiometric column ν_A, one event rate in events/baryon/s (`nB_m3 Y_iY_j <σv>/(1+δ_ij)` in SI); convert each event to ion-state daughters under an explicit branching/thermalization rule; derive Jacobian and heat/neutrino/photon ledger from the same event flux; check `Σ_A Aν_A=0` and nuclear charge including emitted leptons. Keep each numeric provider's domain, source identity, and conditional continuation separate. The pT, neutron and DD anchors above do not supply D(p,γ)He3, DDγ, D(T,n)He4, He3(D,p)He4, T(α,γ)Li7, He3(n,γ)He4, Li6 closure, or fast-neutron transport; other team's live source intake may fill some of those. Do not treat absence here as a zero coefficient.
