# Completed five-case figure CLI — implementation only

No actual final figures were generated by this preparation task. `plot_completed_family.py` needs explicit completed frozen descriptors for ZERO, SHEAR_PLUS, SHEAR_MINUS, SHEAR_HALF_PLUS and SHEAR_HALF_MINUS. Expected q_ref values are 0,+.01,-.01,+.005,-.005; SAME_H is excluded from this primary family.

Manifest `cases` maps each name to the completed-history descriptor documented in `../../convergence/README.md`: exact saved id, elapsed-clock origin, and `{path,sha256}` for history, abundances, config, source_identity and terminal. The reused reader requires actual COMPLETE_REPRESENTED_INTERVAL, full20→4 coverage, every accepted row, aligned six-species H/He/electron inventory and its fixed baryon normalization. Config differences are limited to q_ref and resource/output bookkeeping. All data and Python source identities are recorded.

Run once after actual completion:

    python3 research/axbi_goal_20261014/report/final_figures/plot_completed_family.py --manifest INPUT.json --output research/axbi_goal_20261014/report/final_figures/NEW_OUTPUT

A missing or incomplete case returns typed `NOT_READY` with exact wait fields and null figures, before any PNG creation. Existing output directories are preserved. The input template deliberately has null identities and cannot produce scientific products.

The four output names are `abundance_vs_time.png`, `abundance_vs_Tgas.png`, `flrw_bianchi_abundance_comparison.png` and `delta_abundance_resolution.png`. The first two show the full ZERO baseline; the comparison covers all five independently solved clocks; signed deltas match the frozen1001 ln(a) grid at common mean redshift and retain both signs. Chronological temperature curves have time-direction arrows and are never sorted. Yi=ni/(nH+4nHe), with electron ne/nb labelled charge census and excluded from nuclear inventory. Exact zeros are masked only on log display; every positive value remains in range without a floor or state clipping. Tiny traces imply no validated precision.

An optional `convergence_ledger: {path,sha256}` accepts actual CSV rows with case_id, reference_case=ZERO, comparison_coordinate=ZBAR, matching candidate/reference_zbar, observable=Y_species, and optional numerical_error_estimate. Only actually supplied per-case estimates are drawn as x markers; absent estimates remain unknown. No sign-transfer, gap interpolation, inferred error band, resolved response/null, posterior uncertainty or final science admission is generated. Dashed fixed Y floors are diagnostic thresholds, not error bounds. Unknown interpolation/global/model uncertainty is explicitly separate. Without ledger data the resolution panel says NOT_MEASURED.

The small synthetic smoke check verifies missing-five-case gating produces no PNGs and a known matched-z delta. It is not a render/visual validation or physical history test.
