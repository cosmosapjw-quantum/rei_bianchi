# Source intake publication map

These reports and project-source copies accompany the root-authored DR contract.
The original intake reports/ledgers are copied byte-for-byte. Their absolute
scratch paths and references to private raw retrievals are historical acquisition
records. PUBLISHED_SOURCE_MAP.json maps every included source to a repository
path; exact UTF-8 source bodies are available under source/ in this directory.

The current THEORY_AND_CONTRACT.md controls the selected question. The copied
RESOURCE_ALLOCATION.json is the original provisional allocation. The later
budget hold in intake/BUDGET_HOLD_NOTICE.json, and the root addendum when present,
supersedes its interpretation as permission for numerical or plot execution.
Earlier intake validation/budget suggestions are context, not authorization.

Full copyrighted paper extraction and raw conversation snippets are excluded.
PRIMARY_REFERENCES.json preserves primary URLs, discovery metadata and our own
short summaries. Private raw literature responses remain acquisition evidence,
not Git publication payload. Original source comments and source-scope statements
are retained verbatim; their evaluative wording is not a new independent verdict.

Exact copied project source includes existing vendored numeric coefficient tables
with their original attribution and source locks. No blanket relicensing is made.
These are inert source/evidence copies; packaging does not import or run them.
