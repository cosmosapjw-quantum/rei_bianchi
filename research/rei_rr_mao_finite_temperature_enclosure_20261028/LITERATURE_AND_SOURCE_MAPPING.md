This focused retrieval supplements the fixed project source; it does not refit atomic data or repeat the previous DR literature investigation. Exa and SciSpace were both actually queried. Only primary author/publication sources support adopted definitions.

Abstract/metadata https://arxiv.org/abs/astro-ph/0604144, displayed lines8–27; author formula page https://amdpp.phys.strath.ac.uk/tamoc/RR/, fully displayed lines0–61. The latter directly defines the four-parameter RR expression, low-charge B+C exp(-T2/T) extension, and A/rate units cm^3/s. Its ADAS grid specification is context for the fits, not a continuum error certificate.

Eq5 defines the weighted factor through L=kT alpha f; Eq7 gives the multiplicative power/log fit. The actual native source and preserved prior table-convention evidence fix natural logarithms and the project hybrid use. No newly recomputed source-table fit accuracy is claimed.
