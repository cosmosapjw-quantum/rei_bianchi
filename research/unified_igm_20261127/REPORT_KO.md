# REI Bianchi IGM 통합 연구 결과 · 2026-11-27

같은 종료 적색편이와 같은 경과 고유시간은 이 계산에서 서로 다른 실험이다. $z=20$에서 시작한 짧은 Bianchi I 계산에서 두 비교를 직접 실행하자, 양의 shear와 FLRW 사이 중수소 이온 분율 차이가 약 18,859배 줄었다. 세 미시물리 공급자의 코드와 해당 과학 입력을 REI 아래로 이식하고 BASS·REC·REI의 실제 수락 단계에 연결하면서 얻은 결과다. 원 시나리오의 AX11은 부분 완료이며 정식 DAG 계수는 10/17과 28/88이다.

## 무엇을 통합했나

기준은 REI의 11월 27일 R118-C3T `a3cd7cdc3e7c`이다. 선택된 BASS·REC Rust 크레이트, WU088_HH 및 BASS_HE의 소스·검증 자료, bass_cr의 현재 소스와 필요한 과거 실제 주입 스펙트럼을 한 체크아웃에서 사용한다. 컴파일된 네이티브 예제와 Python wheel의 역할은 구분된다. 공개 Python 진입점은 `rei-igm`이며, 이번에 명시한 네이티브 구간과 고정 셀 실험 전체를 재현하는 명령은 아래와 같다.

```bash
python -m pip install .
python scripts/run_unified_igm.py results/run_20261127
```

## 2차 통합 연구

**원래 수락 단계에서의 시계 대조.** REC HMLA의 $z=20$ 경계에서 $y_{\mathrm{DII}}=x_{\mathrm{HII}}=0.0002101466567140$로 시작했다. BASS는 기하와 광자를 전파하고 REI는 H/He와 온도를 진화시켰다. 승인된 각 구간의 H/He 기체를 이용해 단일 추적 중수소를 적분했다. $q=-0.005,0,+0.005$, 4·8·16·32·64 스텝의 15회와 양의 shear의 동일 고유시간 대조 2회까지 실제 실행했다. 총 468개 수락 단계에서 독립 Python 이력 계산과 온라인 Rust DII가 기록 정밀도에서 일치했다.

| 비교, 64 스텝 | 양의 shear 종료 조건 | FLRW와의 DII 분율 차이 |
|---|---|---:|
| 고정 $z$ | $z=19.999$, 고유시간이 5,029,276 s 짧음 | $+8.992511925\times10^{-10}$ |
| 동일 경과 고유시간 | $z=19.998999987501712$, 약 $4.024\times10^{11}$ s에서 불일치 1.39 s | $+4.768306247\times10^{-14}$ |

32스텝의 동일 고유시간 대비는 $+4.76959645\times10^{-14}$다. 같은 $z$ 대비의 대부분은 이 짧은 구간에서 반응에 주어진 시간으로 설명된다. 잔여량에는 달라진 종료 적색편이와 고정 각도·주파수 격자의 영향이 함께 있다. 같은 64스텝·동일 고유시간에서 흡수 UV 에너지 차이는 $+2.65673\times10^{-14}\ \mathrm{eV/H}$다. 수락 단계별 HI, HeI, HeII 결합에너지와 열을 독립적으로 합했을 때 광자 장부와의 최대 차이는 $4.24\times10^{-21}\ \mathrm{eV/H}$였다. 원 CLI에서 관측기를 켠 경우와 끈 경우의 기본 과학 파일 8개가 바이트 단위로 일치했다. 이 실험은 passive D, CR OFF, 고정 각도·주파수에서의 국소 결과다.

**원 AXBI 이력에서의 H/D.** 각 1,001시점인 다섯 실제 H/He 이력에 전하교환만 포함했다. $q=+0.01$와 ZERO의 차이는 절댓값이 가장 큰 표본에서 고정 $a$ 비교 $-2.47497445\times10^{-6}$, 동일 고유시간 비교 $+1.72113986\times10^{-5}$다. 두 극값은 각각 $z\simeq5.73916,5.69098$에 있다. 시간 표본을 절반으로 줄였을 때 paired 곡선의 최대 변화는 각각 $5.90\times10^{-9}$, $2.93\times10^{-6}$이다. 두 번째 값이 피크의 17.0%이므로 10% 수준의 동일 고유시간 진폭 주장은 보류했다. 이 긴 이력 계산과 위 17회 짧은 구간 계산은 초기조건·shear·범위가 다르다.

**헬륨 광자 에너지 상한.** 원래 F05 92,160행의 H·He 흡수와 탈출 가지에 하나의 광자 수 제약을 동시에 걸었다. 보존과 양립하는 총 에너지 상한은 $2.72138\times10^{47}$ erg다. 각 가지 상한을 독립적으로 더하면 $5.17474\times10^{47}$ erg로 90.15% 커진다. 국소에서 흡수된 선 에너지 중 열의 허용 범위는 42.12–64.93%다. 이는 저장된 F05 상자들에 대한 제약 계산이다. AXBI에는 해당 F05 사건을 재주입하지 않았다.

**실제 AXBI 기체에 대한 조건부 CR·D 개입.** $z=7.9924693$의 다섯 원본 기체상태를 각각 고정하고, $10^{10}$ s 노출, 처음에 빈 proton source, 처방된 $\mathrm{D/H}=2.5\times10^{-5}$, 중성 D 초기조건에서 source ON/OFF를 모두 계산했다. SHEAR_PLUS에서 D 순전하교환은 $8.8421543\times10^{-6}\ \mathrm{m^{-3}}$, 기체 에너지 변화는 $-3.2715971\times10^{-8}\ \mathrm{eV\,m^{-3}}$다. CR은 빠른 전자 $1.2405165\times10^{-15}\ \mathrm{m^{-3}}$, 출생 운동에너지 $5.5151691\times10^{-14}\ \mathrm{eV\,m^{-3}}$를 만들었다. CR를 끄면 두 값은 0이다. 원 projectile의 손실 $7.3546398\times10^{-14}\ \mathrm{eV\,m^{-3}}$은 binding·출생 운동에너지·충돌모델과 REI 문턱의 차이로 나뉘며 독립 합의 잔차는 $-4.77\times10^{-30}\ \mathrm{eV\,m^{-3}}$다. 배경 총 에너지의 binary64 잔차는 이 작은 전달보다 크므로 이 수치는 개별 사건 장부에서 계산했다. 이 초기조건의 전구간 CR 열화·가열·재이온화 피드백은 열려 있다.

## 이론과 독립 검증

닫힌 등온 D/H 전하교환에는 $S=x_{\rm HII}+\eta y_{\rm DII}$ 불변량이 있다. $\dot y=n_H[k_f x(1-y)-k_r(1-x)y]$에서 $x=S-\eta y$를 대입하면 물리적 구간의 유일한 평형으로 수축하며 수축률 하한은 $n_H(1+\eta)\min(k_f,k_r)$이다. 구현은 현재점에서 부호를 갖는 반응량을 직접 적분한다. 극저온 완전 이온 상태에서 기존 root-subtraction 구현이 만들던 가짜 $2.03\times10^{-10}\ \mathrm{m^{-3}}$ 반응을 제거했다. 독립 Radau 해, 소진 경계, 에너지와 전자 수의 동시 변화, 양의 Verner fit 문턱, 같은 사건 재과금 및 중간 재고 소진을 검증했다. 동일한 두 스펙트럼 모멘트 $N,U$로도 선택한 반응률이 $4/27$로 달라지는 유한 반례가 있어 일반적인 공급자 인터페이스에는 분해된 스펙트럼 또는 채널별 적분이 필요하다.

세 Rust 크레이트의 전체 테스트는 BASS 302, REC 145, REI 357개를 통과했다. WU는 원본 143개와 신규 4개를 실행했고, HE는 일반 220개, 원 F05 9개, 신규 4개를 확인했다. CR은 선택한 pytest 35개, 수송 14개, 계약 103개가 통과했고 CuPy 비교 하나는 실행하지 못했다. 독립 설치 wheel에서 세 명령과 물리 회귀 6개를 실행했다. 원본의 모든 역사적 테스트를 재실행했다는 의미는 아니다. 원격 head 목록, 가정, 계산식, 원시 결과, 회귀 영수증은 이 디렉터리 및 components 하위에 있다.

## 과학 DAG와 지연 원인

- **AX11.** T1 ZERO/PLUS는 각각 757,073개 수락 스텝으로 $z=4$에 도달했다. T2의 보존된 두 이력은 이전 실행의 디스크 부족으로 끊겼다. 공유 $18.52717\lesssim z\lesssim19.99581$의 99점에서만 고정 $a$의 HII $D_{12}$ 최대 $1.3066\times10^{-9}$를 확인했다. 원 전구간 T2·에너지·각도 정련을 이어야 한다.
- **R118-C3U.** C3T는 실제 3개 국소 단계에서 직접 모멘트 투영을 검사했다. 바뀌는 coframe에서 광자 출생, scalar mean 단일 소유, 실패한 trial의 rollback, 32 ray 이상에서 시간·주파수 독립 정련을 해야 방향 H/He·REC 결합 주장을 올릴 수 있다.
- **개발이 더뎠던 원인.** 별도 저장소별 테스트의 성공을 합쳐도 물리적으로 같은 사건을 소비했는지 결정되지 않았다. 실제 이식에서 총 에너지 장부가 미세 CR 전달을 가리는 경우, F05 가지 상한의 비동시성, 잘못된 시계 비교가 모두 드러났다. 새 경로는 실제 수락 단계와 독립 사건 장부를 소비한다. 전체 이력의 경우 지배적 장애는 T2 디스크·시간 비용이므로 compact checkpoint와 광자 N/U 허용오차를 지킨 원 시나리오 재개가 우선이다.
- **매 턴 적용.** 대상 관측량, 비교 좌표, 입력과 오차를 먼저 고정한다. 종료 시 변화한 수치 또는 반례를 기록하고 기존 노드의 수용 조건을 평가한다. 그림, 포팅 건수, PR 개수, 반복 감사는 독립 과학 노드로 올리지 않는다. 각 노드의 입력·다음 PR·수용 조건은 `DAG.json`에 있다.

조사 범위는 8개 저장소의 head 2,470개 열거와 관련 branch·PR·백업의 선별 원문 검토다. 연결된 파일 메타데이터 1,593건에는 중첩 폴더 순회 제한이 있었고, 두 차례의 전체 대화 검색은 현재 세션에서 사용할 수 없었다. 공급자가 반환한 범위를 넘어선 비공개 스레드·백업의 완전성은 확인되지 않았다.
