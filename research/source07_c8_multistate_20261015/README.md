# C8 multistate positive sparse age quadrature (2026-10-15)

Independent scoped reference computation reuses exactly the C8 frozen-gas two-species quadrature from `research/source07_c8_age_compression_20261015/experiment.py`. Run: `OPENBLAS_NUM_THREADS=1 python3 research/source07_c8_multistate_20261015/experiment.py`. 36 manufactured equal-weight ages, three signed q values -0.01/0/+0.01, 12 angular nodes, threshold-split 16 Gauss energy nodes. Training gas states in units of the original proper HI/HeI densities: (1,1),(.6,1.3),(1.4,.7). Unseen holdouts: (.8,1.1),(1.2,.9),(.4,1.5). Target five nonnegative integrated functionals: photon count, photon energy, HI absorbed, HeI absorbed, and photoheat; require positive age weights with sum=1. LP solves all three training state constraints together. Input source epochs are manufactured equally weighted, not a verified physical MD14 continuous emissivity timeline.

Observed: single-state LP retains five ages, multistate LP retains eight ages. Max unseen-state HEAT relative error for single-state about 1.358e-3; multistate about 4.33e-11 for every q (see results.json). This validates a *finite sampled-state sensitivity improvement*, not a universal opacity error bound. HeII gas density is zero here, HeII absorption is untested. No dynamically evolved gas, proper source-age emissivity, true photon conservation under chemistry, time stepping, integration error enclosure, Rust implementation, parallel scaling or total memory measurement were performed. The ratio 36/8 refers only to age nodes, not total solver RAM. LP constraint combinations have arbitrary scales; normalized rows are used for conditioning, positive weights checked. Holding exact gas-state responses in the constraint matrix is an oracle experiment, not an online production method.
