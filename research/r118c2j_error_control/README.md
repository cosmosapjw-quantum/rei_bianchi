# C2J: covariant REI time control
The original default remains backward Euler, eight or more angular nodes and its original adaptive controller. Opt-in continuous_birth analytically advances the frozen opacity old/birth populations and uses time-averaged stocks for photoevents. nonmonotone_search tests explicit larger candidates, retaining the original shape and gas criteria and additional rate/pool criteria. flrw_two_ordinate is allowed only in the exactly isotropic FLRW lane. No global-error or full-range convergence admission.
PROFILE.tsv and CONTINUOUS_PROFILE.tsv are actual full/half probes at the initial state and prior C2I checkpoint. RUNS.json records new IC trials, all raw hashes including source_identity.txt and terminal checkpoint, and audited gates. Earlier intermediate executable hashes were not captured prior to rebuild. Final executable hash is recorded. Terminal configurations/checkpoints/source identities are compressed here. Original C2I run was not overwritten or resumed across binary identities.
Reproduce with axbi_covariant_recovered and the preserved config, see its existing CLI. New controller uses same local targets; its capped executions are not wall-clock-equivalent accuracy benchmarks. No global history claim.
