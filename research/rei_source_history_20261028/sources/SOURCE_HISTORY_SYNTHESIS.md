## Direct five-stock tracking derivation

The following is a direct derivation for the retained phenomenological operator, not a new literature theorem or a calibrated abundance prediction. Let x=(B_n,B_T,n,TI,TII)^T in particles/Href, with proper time t. Let a_n=ks,n+ke,n+lambda_n/gamma_n, a_T=ks,T+ke,T+lambda_T/gamma_T, L_n=lambda_n+kcap+kesc, L_T=lambda_T+kesc. All rates are nonnegative; decay provides strictly positive loss. The existing model fixes gamma=1. Let r be recombination and Gamma the TI photoionization hazard. Parent targets outside these five stocks remain prescribed.

    x' = A(t)x + b(t),
    A = [ -a_n    0       0          0             0
           0    -a_T      0          0             0
          ks,n    0     -L_n         0             0
           0      0       0      -(L_T+Gamma)       r
           0     ks,T     0         Gamma      -(L_T+r) ],
    b = (S_fast,n, S_fast,T, I_n, I_TI, I_TII)^T.

This matches the selected p(n,gamma)D sink; no new n-to-T capture channel is silently added. Atomic T exchange and fast-to-thermal slowing are internal transfers in this five-stock subsystem. A is Metzler. Its column sums are

    -(ke,n+lambda_n/gamma_n), -(ke,T+lambda_T/gamma_T),
    -L_n, -L_T, -L_T.

Thus the ordinary 1-norm already supplies a common positive weight vector w=(1,1,1,1,1). With c(t) the minimum of these five positive removal rates, its matrix measure satisfies mu_1(A)<=-c(t). Arbitrarily changing Gamma and r preserve this contraction because their transfers cancel in column sums. This cancellation does NOT imply that ion fractions track rapidly changing Gamma: the moving equilibrium still contributes its derivative.

For any signed homogeneous perturbation v'=Av, componentwise comparison gives D+|v|<=A|v|. Summing gives D+||v||_1<=-c(t)||v||_1, hence the transition operator obeys ||Phi(t,s)||_1<=exp[-integral_s^t c(u)du]. Since every frozen A is strictly stable, x*(t)=-A(t)^-1 b(t) exists and is nonnegative. For absolutely continuous x*, e=x-x* obeys exactly

    e(t)=Phi(t,t0)e(t0)-integral_t0^t Phi(t,s) x*'(s) ds,
    ||e(t)||_1 <= exp[-C(t,t0)]||e(t0)||_1
                 + integral_t0^t exp[-C(t,s)]||x*'(s)||_1 ds,
    C(t,s)=integral_s^t c(u)du.

If c>=c0>0 and ||x*'||_1<=V on the interval, this becomes the uniform bound

    ||e(t)||_1 <= exp[-c0(t-t0)]||e(t0)||_1
                 +(V/c0)(1-exp[-c0(t-t0)]).

Differentiating the frozen equation gives x*'=-A^-1(A'x*+b'). Because ||A^-1||_1<=1/c0, an explicit sufficient bound is V<=[sup||A'||_1 sup||x*||_1+sup||b'||_1]/c0. The directly evaluated x*' can be much sharper. In eta coordinates the exact expression is

## Initial relaxation, residual and physical calibration are distinct

The saved thermal n/T baseline is zero; the old pointwise QSS stock is a separate substituted diagnostic state. The historical calculation did not supply evolved fast-stock initial conditions. A transient calculation must state them. Taking all five stocks initially zero is a legitimate declared new initial condition, but gives e0=-x*(t0), generally nonzero. It does not establish first-epoch QSS. Initial equilibrium matching is a different explicit assumption. Without a finite bound on initial fast stocks there is no numerical uniform state-error certificate, although the conditional bound remains valid.

Even constant coefficients and constant forcing supply the exact scalar counterexample: for x'=s-lambda x with x(t0)=0, x*=s/lambda and x(t)=x*[1-exp(-lambda(t-t0))]. In the scalar variable-coefficient case, x*=s/lambda and the exact error is e(t)=exp[-integral lambda]e0-integral exp[-integral_s^t lambda]d(s/lambda)/ds ds, directly exhibiting both causes of lag.
