# 승인 범위의 최소 갱신

기존 CLAUDE/handoff의 “production node chemistry … remain unauthorized”는 과거 claim/permission 상태를 담는다. 최신 사용자 지시는 production Rust 수정과 통제된 실행, 여섯 저장소 원전의 선택적 통합, 추가 핵종 연구, theory R1–R10 후 coding C1–C10, 백업·publication 작업을 허용한다. 해당 과거 문장으로 현재 개발을 금지하지 않는다.

허용된 구현·실험과 과학적 admission은 구분한다. 기존 영수증·SCENARIO_LOCK·admitted 결과를 소급 변경하지 않는다. 새 source는 새 output/identity를 쓰며 changed-seam 결과와 독립 심사로 해당 범위만 결정한다. clock 연결은 반복 투영 문턱 결함을 해결하지 않으므로 전체 생산 승인을 뜻하지 않는다.

Rust canonical은 Python 원전의 수학·tests를 읽어 Rust로 이식하는 일을 금지하지 않는다. HH thermal rate 미공급, CR-on의 source/electron·energy 계약, D donor/rates 부족은 실제 물리 입력 문제다. 새로운 blanket 승인 절차나 모든 branch의 병합 조건으로 바꾸지 않는다. 실행 가능한 CR-off FLRW와 standalone D/H 단위를 계속한다.

작업자는 요청 모델 gpt-6.1-sol high, 독립 심사는 gpt-6-astra high로 기록한다. runtime identity는 별도 관측 없이는 unknown이며 요청값을 관측값으로 쓰지 않는다.
