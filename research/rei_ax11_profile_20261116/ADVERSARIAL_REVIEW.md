## Independent representation checks actually executed

`harness/validate_native_consumption.py` checks all 27 native windows and 28,443 history rows against their binary state traces. Maximum normalized charge reconstruction discrepancy is `1.3877787807814457e-17`; temperature reconstructed from thermal energy differs by at most `9.094947017729282e-13 K`. Trace/history scale factors match exactly. All photon-count, augmented-energy and J1 gate residuals lie within their original tolerances. This validates data consumption and conservation diagnostics, not a global evolution-error theorem.

## Failures preserved

1. The reused sparse-file regression received SIGXFSZ under a 64 MiB file limit because its intended sparse guard fixture is 224 MiB. The test-only limit was explicitly corrected to 256 MiB in an owned TMPDIR; physics windows retained 64 MiB. Original failure and successful test receipts remain.
2. A remote file-transfer timeout left a controller absent. Bootstrap failed before science execution. It was recorded as an environment/transfer failure and the exact file was then verified before the bounded run.
3. Both original-start T2 runs stopped with `AXBI_REJECT_CAP`, zero accepted states and 60 trials each. Their counters, component rows, logs and start/end checkpoints remain. The separately bound floor-start results do not erase them.
4. Analysis first treated dimensional `VALUE` ledger rows as tests; the consumer was corrected to the actual schema before issuing its verdict. An endpoint interpolation roundoff was fixed using exact supplied endpoint identities, with no outside-domain extrapolation.
