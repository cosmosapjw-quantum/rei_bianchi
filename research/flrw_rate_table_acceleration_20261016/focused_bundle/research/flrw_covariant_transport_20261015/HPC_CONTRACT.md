## Parallel-equivalence contract

For cell k, `prepare` computes a list P_k solely from its own (N,Q,L,H), immutable ray geometry, thresholds and provider. No other cell enters that calculation. Therefore computing P_k concurrently and concatenating P_0,P_1,... in the existing order reproduces the serial node sequence. Each cell must retain its original quadrature/tilt iteration order and diagnostics operations. Select the lowest-index failing cell deterministically, after collecting launched work.

For frozen prepared node l, absorber trial n and dt, the independent map is

    opacity_l = ordered_sum_j(n_j sigma_lj)
    survivor_l = w_l / (1 + dt c opacity_l).

Per-node photo rates, heating and species events are independent before their fold. If this secondary optimization is later selected, parallelize these maps; preserve the original serial fold of node contributions in node order and species j=0,1,2. The compensated per-cell survivor and endpoint-distance sums retain their original node order. Global Gamma/heat/events/binding/heat-budget `+=` retain their original order. **Do not replace this by sums of worker partial sums:** floating addition is not associative, and thread-count-dependent rounding can change the adaptive trajectory.

A practical implementation is an indexed contribution buffer. Workers compute node values and/or whole-cell local survivor moments; the coordinator performs ordered global reduction. Cell-local work is owned by one worker, so there is no atomic floating-point update. The serial and parallel paths call the same scalar kernel. Preserve multiplication association, explicit mul_add positions, finite/domain tests and threshold equality. Cache upper-anchor decisions or immutable offsets once per prepared stage where this is exactly equivalent. A residual-only path may avoid returning unused vectors, but may not skip the existing survivor/moment/nonfinite validity decisions.

Each Newton iteration depends on the previous iteration; line search depends on the accepted preceding trial. Accepted cosmological time steps depend on their predecessors. They remain sequential. Four finite-difference Jacobian columns are mathematically independent after the baseline residual, but their current positive-perturbation/fallback behavior and RHS budget accounting make them a secondary optimization, not required for the first complete cell-parallel implementation.

The full-step branch is independent of the two-half-step branch, but half2 depends on half1. With three equal-cost tentative solves the serial cost3T becomes max(T,2T)=2T, so **branch-only speedup is at most1.5**, not2. If branch parallelism is implemented, keep each branch state and counts private, reserve finite budget before launch, count every actually launched RHS even after sibling failure, then commit in serial error-priority order. Existing evaluate increments the RHS counter before gas-domain validation. Near a cap, serial fallback is valid. Avoid nested worker starvation: only coordinator threads submit leaf cell work to the shared pool. Branch parallelism is optional after cell-level scaling is measured.

## Executor and memory

Selected first implementation: a **persistent bounded std worker pool**, created once for a process/run, with owned Arc snapshots and indexed output chunks. Current dependency-free crate makes this immediately stageable offline. Prepare owns immutable state/geometry for the task; prepared absorption is shared once per chemical stage, not cloned per Newton RHS or per worker. Bounded channels/jobs, dynamic scheduling of small contiguous cell chunks, and fixed indexed output ordering provide load balance without nondeterministic arithmetic. No per-residual OS-thread creation with repeated std::scope spawning. If the implementer chooses an already staged persistent Rayon pool instead, it must satisfy the same fixed worker-count, indexed result and no parallel-reduce contract; availability is an implementation dependency, not a scientific permission issue.

Pool scheduling can vary; floating operations cannot. Avoid mutex-protected floating accumulators, mutable global diagnostics, oversubscribed nested pools and repeated full-cache copies. Keep reusable scratch per worker bounded by MAX_NODES_PER_CELL=1024; use measured capacity/RSS telemetry. Do not allocate RAM merely to appear to use128GB.

Purposeful memory: state is O(number of ray-energy cells); prepared nodes and replay contributions are O(total quadrature nodes). On the current64-bit layout each existing node is approximately72 bytes; an explicit full replay payload can be bounded near136 bytes/node, so a conservative208 bytes/node plus state/scratch is useful planning. At512×16 cells and1024 nodes/cell, that is about1.625GiB for one prepared cache plus payload; actual occupancy is much smaller. Report actual size_of/capacity rather than assuming this estimate. Five cases fit the host without an artificial8GiB-per-case restriction; enforce the frozen112GiB aggregate host budget and avoid swapping. More memory may support genuine finer grids/cache reuse, not change the scientific closure.
