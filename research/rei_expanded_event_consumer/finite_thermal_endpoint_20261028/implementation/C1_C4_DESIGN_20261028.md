## C3: computational form and numerical design

Planned implementation paths remain the R1-owned paths: implementation/finite_thermal.py, test_finite_thermal.py, run_once.py and README.md. None is authored or executed by this checkpoint.

The scalar core uses standard-library Fraction with exact decimal/rational strings and rejects accidental float/bool inputs. Inputs and outputs carry the units and common-volume convention fixed in R3. Guard Na,Ta,c_v,D,E before division. Return an immutable result containing D,E,T_hat, the rational ratio T_hat/Ta and both positive logarithm arguments. Do not claim an exact rational value for a generic logarithm. The tangent of log T is rational and can be returned exactly.

The stored diagnostic takes Ua,Ub,Nb independently, returns r0,r_bal,rE,rN and the exact discrepancy, and never mutates source data. The interval wrapper accepts only supplied nonnegative radii and verifies D-eN>0 and, for a wholly positive temperature interval, E-eE>0. Null physical inputs propagate to an unresolved physical-bound field, while algebraic fixture bounds remain separately usable.

The composition routine stores R and signed count/energy/work increments. Combine two segments by (x01,R01) followed by (x12,R12) -> (x01+R01*x12,R01*R12), separately for each increment. This avoids subtracting or adding temperature increments as if they were extensive. Include the cross term delta R01*x12 in tangents.

Arithmetic uses a fixed number of rational operations per scalar map; cost depends on integer bit lengths and is not measured constant-time performance. Multi-segment folding has a linear number of such operations, with possible rational bit growth. Input decoding and source identity checks are separate costs. Exact rational arithmetic eliminates floating roundoff for the declared inputs but not source decimal truncation, quadrature, transport, temporal, model or EOS error. There is no new timestep, grid, interpolation, clipping or closure parameter. General-EOS inversion and polytope optimization remain outside the implementation scope; their conditional derivations are retained in R5.
