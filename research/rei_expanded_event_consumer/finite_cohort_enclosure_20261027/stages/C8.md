# C8 — 수치·재현성

상태: **BLOCKED_RUNTIME_EVIDENCE_NOT_RUN**. 원래 DAG: 작업 **32/88**, 중앙 **27/88**, 증분 **0**.

생산 primitive는 선언된 rational input에 정확한 Fraction 연산을 적용한다. 이 설계의 analytic error 설명과 실제 코드의 실행 검증을 구분한다. 새 runtime CPU·wall·peak memory·Python version·성능비교는 측정하지 않았고 null로 기록했다. 실행하지 않은 값을0 또는 PASS로 채우지 않았다.

C8_REPRODUCIBILITY.json은 고정 code blobs, exact arithmetic scope, 알고리즘 비용의 주장 범위와 최초 실행 계약을 연결한다. 현재 유효한 자원 기록은 BUDGET_STOP.json이다. 최초 계약의 임시 packaging 예상은 historical record로 보존하며 최종 실측 누적을 우선한다.

R1–R6의 실제 ZIP/CRC/SHA와 ACK를 재사용한다. R7 이후 원문 체크포인트는 Git 원문과 Drive 원문을 비교하고 양쪽 완료 ACK·크기를 확인했다. Whole-unit ZIP 생성은 별도 presentation 예산 승인 전 보류다. 원문 source bundle은 승인된 게시·백업 경로로 전달한다.

수렴·벤치마크를 새로 실행하지 않는다. 현재 필요한 검증은 정확한36개 최초 controls이며, 기존 full suite나 provider 계산을 반복할 이유로 확대하지 않는다.
