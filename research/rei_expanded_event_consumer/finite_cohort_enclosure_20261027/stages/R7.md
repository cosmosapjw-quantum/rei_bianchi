# R7 — 판별 검증

상태: COMPLETE_ANALYTIC. 원래 DAG: 작업 **32/88**, 중앙 **27/88**, 증분 **0**.

순수 정리의 증명은 CAS나 수치 샘플에 의존하지 않는다. Root와 독립 검토자가 다음 정확한 사례를 손으로 대조했다.

| Cohort와 누적 정보 | 관측창 | 정확한 infimum / supremum |
|---|---|---|
| h=1 on[0,1], grid(0,2), F(2)=1 | [0,1] | [0,1] |
| 동일 | [1,2] | [0,1] |
| 동일 | [0,2] | [0,1] |
| 동일 | 앞 두 창의 shared kernel 합 | [0,1] |
| h=1 on[0,1], grid(0,1,2), F(1)=F(2)=1 | [1,2] | inf0 비달성, sup1 달성 |
| h=s on[0,2], grid(0,1,2), l=(0,1,3), u=(0,2,4) | [0,1] | [0,1] |
| 동일 | [1,2] | [1/2,4] |
| 동일 | [0,2] | [1/2,5] |

Box 사례의 U01+U12=2>U02=1은 개별 최적 상한을 합치는 오류를 판별한다. 실제 고정 F의 관측량은 가법성을 유지한다. Lower nonattainment는 delta_epsilon에서 D=epsilon>0이고 epsilon→0인 구성으로 증명했다. Affine 환원은 기존 결과와 telescoping 증명을 재사용한다.

새 과학 실행과 CAS evaluator 실행은0회다. Wolfram context 실제 조회와 공식 문서 위치는 R2에 기록했다. 새20tests와 이전 미실행16tests는 예산 승인 후 첫 검증을 위해 준비됐으며 실행 PASS로 기록하지 않는다.
