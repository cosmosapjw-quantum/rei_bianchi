# C3 — 수치 설계

상태: COMPLETE_DESIGN. 원래 DAG: 작업 **32/88**, 중앙 **27/88**, 증분 **0**.

## 유한 연산으로의 정확한 연결

이 구현은 선언된 rational piecewise-affine history에 대해 analytic primitive와 finite LP의 exact arithmetic을 사용한다. Kernel extrema를 sampling 또는 quadrature로 근사하지 않는다.

1. 입력의 partition과 이미 닫힌 monotone cumulative bounds를 검증한다.
2. 여러 창은 \(K=\sum_j\lambda_j[G(B_j-\tau)-G(A_j-\tau)]\)를 먼저 구성한다.
3. 각 cell에 양 끝과 모든 shifted history breakpoint를 넣어 quadratic piece를 분리한다.
4. 열린 smooth piece에서 \(K'=p+q\tau\)를 만들고 \(q\ne0\), \(-p/q\)가 내부일 때 그 점을 후보에 넣는다.
5. 유한 후보의 정확한 min/max로 cell costs를 얻는다.
6. \(V=\{0,l_k,u_k\}\)에서 prefix DP를 수행하고 parent chain을 역추적한다.

## 의미와 오차

이산화 오차는 위 선언된 source family와 정보집합의 extremal problem에 대해 발생하지 않는다. 입력의 물리적 불확실성이 사라진다는 뜻은 아니다. Exact Fraction 연산은 roundoff를 만들지 않지만 실제 runtime 구현이 계약을 수행하는지는 최초 테스트로 확인해야 한다.

LP는 compact chain polytope에서 minimum/maximum을 달성한다. 원래 half-open cell의 F-space에서는 최적 atom 위치가 제외된 왼쪽 끝점일 수 있으므로 반환값의 의미는 INFIMUM/SUPREMUM이다. 위치 flag는 이를 노출한다. 같은 chain의 cell mass를 오른쪽에서 접근시키면 모든 grid constraints를 유지하며 sharp endpoint에 접근한다.

Nonnegative single-window kernel은 음의 count/energy contribution을 만들지 않는다. Signed combined observable의 음수 값은 음수 주입을 뜻하지 않는다. 고정 F의 창 가법성은 유지되고, 서로 다른 최적 F를 허용한 scalar upper의 가법성은 일반적으로 유지되지 않는다.

## 계산량과 재현성

DP 단계는 \(O(m|V|)\) arithmetic operations이다. Parent 저장은 \(O(m|V|)\), 작업 row는 \(O(|V|)\)이며 extrema 전처리는 별도다. Rational numerator/denominator bit cost와 실제 CPU·memory는 측정 전 UNKNOWN이다. Deterministic earliest ties와 frozen 결과로 같은 exact input에 대한 재현 가능한 witness를 정했다.

표준 라이브러리 Fraction/dataclasses/unittest만 사용한다. ODE·NCP·projection·quadrature·provider solve나 기존 full suite는 호출하지 않는다. Runtime 결과와 성능 우위는 아직 주장하지 않는다.
