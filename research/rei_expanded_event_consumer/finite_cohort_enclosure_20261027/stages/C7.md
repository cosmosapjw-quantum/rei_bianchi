# C7 — 과학 검증

상태: **PARTIAL_STATIC_AND_ANALYTIC; RUNTIME_PENDING**. 원래 DAG: 작업 **32/88**, 중앙 **27/88**, 증분 **0**.

이론–구현의 정적 대응은 독립 검토로 확인했다. 비음수 source endpoint 검증, \(K'=h(A-\tau)-h(B-\tau)\) 부호, exact primitive, half-open cell 질량, shared cumulative chain과 combined kernel은 R5 정리와 일치한다. 차원은 \([h]=s^{-1},[G]=[K]=1,[D]=[F]\)이며 fixed-F 창 가법성과 zero-window/empty-cohort 극한은 증명과 정적 테스트 기대값에 반영됐다.

이 검토는 실제 실행이 intended equation을 계산한다는 최종 증거를 아직 포함하지 않는다. C6 이후 실제20controls와 기존 미실행16controls가 통과해야 실행 대응의 의무가 닫힌다.
