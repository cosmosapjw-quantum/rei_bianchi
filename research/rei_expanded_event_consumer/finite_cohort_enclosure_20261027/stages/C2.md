# C2 — 식–데이터–코드

상태: COMPLETE_STATIC_MAPPING. 원래 DAG: 작업 **32/88**, 중앙 **27/88**, 증분 **0**.

실제 작성된 cohort_bounds.py와 test_cohort_bounds.py를 독립 검토자가 읽었다. Root는 동일 두 원문을 Drive original-file fetch로 가져와 게시 입력에 결속했다. 구현8433bytes, 테스트8944bytes이며 각 원본 파일은 이미 양쪽 backup ACK를 확보했다. C5에서 이 원문 그대로 Git에 게시한다.

호출 경로는 다음과 같다.

| 단계 | 실제 함수 | 입력·출력 의미 |
|---|---|---|
| 공개 entry | cohort_bounds / combined_cohort_bounds | 하나의 scalar observable과 동일 누적 정보집합 |
| 계약 확인 | _validate / _segments / _fraction | source partition, proper-time windows, monotone closed bounds와 cap |
| history 누적 | _primitive | 정확한 affine primitive와 선택 cohort clamp |
| objective 작성 | _ranges | 모든 window kernel을 먼저 합친 함수 |
| extrema 작성 | _ranges / _density_coefficients | shifted breakpoints와 내부 rational derivative root |
| chain 최적화 | _optimize | 유한 bound levels와 prefix optimum |
| 반환 | BoundsResult / CellExtremum | inf/sup, endpoint chain, limiting atom 위치와 excluded-left flag |

실제 source raw4/PREEXEC와 native25 interface는 이 primitive의 호출 입력이 아니다. 이 함수는 이미 닫힌 bounds를 받고 source 파일을 다시 파싱하거나 SI 변환·recipient-density projection을 하지 않는다. 실제 연결은 source-matched response 계약을 충족한 호출자가 맡는다.

기존 positive affine 식을 일반 cohort에 그대로 적용할 수 없었던 원인은 F-integral weight의 부호 변화다. 이를 Stieltjes kernel로 바꾸고 cell 내부 질량 위치를 최적화했다. 여러 창의 sharp bound를 각각 더하는 오류는 combined kernel을 먼저 만드는 실제 함수로 처리한다.

실패 분류: 현재 남은 실행 중단은 resource/policy gate이며 이론 반례나 구현 runtime failure로 분류하지 않는다. 실제 provider 미결속은 입력 의존성이다. Independent static review는 blocking finding0이며 테스트 실행을 대신하지 않는다.
