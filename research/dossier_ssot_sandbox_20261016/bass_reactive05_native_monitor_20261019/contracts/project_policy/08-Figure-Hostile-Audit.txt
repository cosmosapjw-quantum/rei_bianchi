[TITLE]
Figure Hostile Audit + First Repair Pass

[ONE-LINE PURPOSE]
제공된 figure(또는 figure set)를 논문 투고 직전 수준으로 강하게 감사하라.
목표는 예쁜 그림 칭찬이 아니라, 의미 불일치, 겹침, 가독성 저하, 인쇄 축소 후 판독 실패, subplot 구조 문제를 적발하고 1차 수정까지 제안/수행하는 것이다.

[IMPORTANT MODE DECLARATION]
- 이 모드는 “그림 미화 모드”가 아니다.
- 먼저 audit ledger를 만들고, 그 다음에만 수정으로 들어가라.
- 수정 중 새로운 의미 왜곡이 생기지 않도록, semantic consistency를 항상 최우선으로 둬라.

[SCOPE]
검토 대상:
1. figure image(s)
2. figure 안의 텍스트/수식/범례/축 라벨/패널 레이블
3. 가능하면 관련 원문 문단, 캡션 초안, 플롯 생성 의도
4. 여러 패널이 있으면 panel 관계까지 포함

[TARGET PRINT ASSUMPTION]
- 사용자가 별도 지정하지 않으면 아래 두 경우를 모두 가정하라:
  A. single-column width ≈ 89–90 mm
  B. double-column width ≈ 180–183 mm
- 축소 후에도 텍스트/수식/축 라벨/범례가 읽혀야 한다고 가정하라.
- 사용자가 목표 저널을 지정하면 그 기준을 우선하라.

[AUDIT PRIORITIES]
P0. figure가 논문 주장과 의미적으로 불일치
P1. 겹침/잘림/과도한 축소로 인해 읽기 어려움
P2. subplot 구조/legend/annotation 배치가 비효율적
P3. 미세한 시각적 일관성 문제

[PHASE 1 — FIGURE INTENT RECONSTRUCTION]
1. 이 figure가 “무엇을 보여주려는 그림인지” 1~3문장으로 재구성하라.
2. 각 패널이 있다면 패널별 목적을 적어라.
3. 가능하면 가상의 caption draft를 먼저 생성하라.
4. 그 caption이 실제 그림과 맞는지, 그리고 논문 원문 주장과 맞는지 비교하라.

[PHASE 2 — SEMANTIC CONSISTENCY AUDIT]
다음을 점검하라:
- 캡션 가설과 실제 plot 사이의 불일치
- 축 라벨/단위/범례/기호의 의미 충돌
- figure가 원문보다 더 강한 주장 또는 다른 주장을 암시하는지
- subplot 사이에 비교 가능성이 암묵적으로 요구되는데 scale/normalization이 달라서 오해를 부르는지
- 색/마커/선형식이 의미 구분에 실제로 충분한지

[PHASE 3 — PRINT-SIZE / LEGIBILITY AUDIT]
실제 논문 축소를 가정하고 아래를 점검하라:
- 글자 크기, 수식 크기, tick label, legend, annotation이 읽히는지
- 글자/수식/legend/markers/lines가 서로 겹치는지
- 너무 얇은 선, 너무 작은 마커, 너무 빽빽한 tick, 과도한 subplot spacing이 있는지
- 텍스트가 textured/shaded area 위에 놓여 읽기 어려운지
- subplot label(a, b, c...)과 본문 레이블 체계가 일관적인지
- figure 안에 들어갈 필요 없는 설명이 과도하게 들어가 있지 않은지

[PHASE 4 — LAYOUT / STRUCTURE AUDIT]
다음을 판단하라:
- 현재 하나의 figure로 유지하는 게 맞는지
- subplot 분리 또는 재배치가 더 나은지
- legend를 공통 legend로 뽑는 게 나은지
- annotation을 줄이고 caption으로 보내는 게 나은지
- 같은 의미의 시각 요소(색, 선, 마커, 폰트, 패널 간 간격)가 통일적인지

[PHASE 5 — SELF-ADVERSARIAL CHECK]
반드시 아래 질문을 하라:
- “이 그림이 예뻐 보이지만 실제로는 읽히지 않는 부분은 어디인가?”
- “이 그림이 독자에게 잘못된 비교를 유도하는 부분은 없는가?”
- “이 caption을 논문에 넣었을 때, 독자가 그림만 보고 오해할 가능성은 없는가?”
- “이 figure가 주장보다 과한 확신을 시각적으로 암시하고 있는가?”

[PHASE 6 — BOUNDED VERIFICATION]
- CoVe:
  (i) 임시 audit 결론 작성
  (ii) 검증 질문 5~8개 생성
  (iii) 질문별 독립 답변
  (iv) audit 결론 수정
- CCoT:
  아래 두 해석을 대비하라
  A. “현재 figure 구조를 유지하는 편이 낫다”
  B. “subplot 분리/legend 외부화/annotation 축소가 낫다”
  그리고 어느 쪽이 더 타당한지 판단하라.
- 과도한 방법론 호출 금지. 이 phase의 목적은 audit 결론 검증이지 새 figure 아이디어 발명 경쟁이 아니다.

[PHASE 7 — FIRST REPAIR]
audit 결과를 바탕으로 1차 수정안을 제안하거나, 편집 가능하다면 실제 수정 방향을 제시하라.
수정 우선순위:
1. semantic mismatch 제거
2. overlap 제거
3. 축소 후 가독성 확보
4. subplot/legend 구조 개선
5. 미세한 aesthetic consistency
수정은 “최소 수정으로 최대 판독성 개선” 원칙을 따르라.

[OUTPUT FORMAT]
1. figure intent summary
2. hypothetical caption
3. semantic consistency audit
4. print-size / legibility audit
5. layout / structure audit
6. ranked error ledger (P0~P3)
7. first repair plan
8. 최종 1차 판정:
   - PASS
   - REVISE
   - REBUILD PARTIALLY
   중 하나
9. 판정 사유 한 줄
