# 공유 사건·대조 지원함수 합성 결과

단일 최초 실행은 종료 코드 0으로 완료되었고, 새 검증 6개 군이 모두 통과했다. 실제 저장 결과 7개를 고정된 선택자로 읽고 실행 전에 SHA256을 확인했다. 기존 생산자 코드·최적화·BFS·최소절단·ODE·속도표 계산은 실행하지 않았다. 독립 참조는 생산자 모듈을 가져오지 않고 정확 유리수 연산으로 별도 계산했다.

공통 원리는 사건의 같은 잠재 변수를 유지한 채 응답과 대조를 적용한 뒤 절댓값을 취하는 것이다. 따라서 상관 지원반경은 `sum |cAB|`이고, 저장소별로 먼저 독립 구간을 취하는 `sum_i |c_i| sum_j |(AB)_ij|`보다 크지 않다. 이 결과는 선언된 유한 불확실성 집합의 정확 지원함수이며 경험적 물리 정확도나 신뢰구간 주장과 다르다.

- REC/WU: 실제 8개 선의 부호 있는 에너지 결함을 새로 선언한 비음수 사건 진폭과 WU 형상의 시간 이력에 적용했다. W=3/8은 저장된 적분을 재사용했다. 공유 잠재변수의 256개 꼭짓점을 모두 직접 계산하여 중심±반경의 달성을 확인했다. 상관 반경은 독립 저장소 반경보다 엄격하게 작다. 이것은 실제 HD 개체수 진화, 열가열 또는 에너지 보상항이 아니다.
- CR: 저장된 case-A의 완전한 작은 진단 다면체 꼭짓점 3개를 직접 축약했다. 원자 주변합 (1,1), d, C=0 및 수정 면조건을 확인했다. 에너지밀도 범위는 49.18–79.01 eV m^-3이며 독립 사건좌표 상한 167.695 eV m^-3보다 엄격하다. 실제 3200 원자 소스의 완성 주장은 없다.
- HE: v>0 및 공분산 -v를 보존하면 두 딸의 합 분산은 0, 불균형 분산은 4v다. 공분산을 버린 2v는 전자에는 과대, 후자에는 과소다. 공분산에서 확정 지원반경을 추론하지 않았고, MeV를 REC의 J와 혼합하지 않았다.
- REI 대조: 새 저장 결과에서 정수 인접차분 D만 읽었다. D1=0과 선언된 추상 응답에서 공유 반경 0, 독립 상자 반경 2를 확인했다. 두 시간 셀의 같은 잠재 계수 +1,-1도 결합 반경 0, 독립 셀 합 2다. 실제 Q·LOO를 재계산하거나 에너지 응답으로 해석하지 않았다.
- 수치 경계: BASS의 한 교차블록 성분과 VigilODE의 고정 계량 Gamma는 별도로 평가했다. 같은 기본 커밋·바인딩이어도 서로 다른 전자 가중치 [2,3,5]와 [1,1/100,1/10000]를 결합하려는 시도는 거부되었다. 일관된 합성 스칼라 예에서는 epsilon=43/100, 투영 상한=86/100이며 불일치항 생략의 33/100을 거부했다. 실제 응답노름 1이나 물리적 결합 경로를 증명한 것은 아니다.

저장 그림 `correlation_gaps.svg`와 PNG는 REC J m^-3, CR eV m^-3, HE MeV²/사건분포, 추상 무차원 대조를 각각 별도 축에 표시한다. 표시 숫자만 근사이며 정확 유리수·꼭짓점·달성 증인은 RESULTS.json과 REFERENCE.json에 보존했다. PNG를 열어 라벨과 잘림을 확인했다.

자원은 과학 계산·독립 참조·SVG 저장 및 PNG 렌더를 합쳐 CPU 0.294063초, 자식 벽시계 0.330572초, 최대 RSS 64036 KiB였다. 별도 래퍼 CPU는 0.00444초다. 상한은 새 독립 단위 15 CPU초/30 벽시계초/512 MiB이며 기존 소유자 예산을 옮기거나 초기화하지 않았다. 호스트·전체 오버헤드는 미측정 UNKNOWN이며 0으로 두지 않았다. 실패·과학 재실행·자동 재시도는 없었다.

최초 실행 명령은 `python3 run_bounded.py`이며 기존 로그가 있으면 재실행을 거부한다. 래퍼는 작업의 `helpers/bounded_child.py`를 사용한다. `INPUT_BINDINGS.json`, `EXACT_INPUTS.json`, 독립 참조, 원시 stdout/stderr, 개별 자식 영수증 및 합산 RUN_RECEIPT.json을 함께 보존해야 한다.

현재 상태는 유한 조건부 합성 통과 및 새 비저자 C9 검토 대기다. 실제 공통 사건 이력, 정상화, 관측 응답·전파자, BASS/VigilODE 입력·계량 일치 및 일곱 저장소의 물리 연결은 제공되지 않았다. 정식 진행 28/88의 증분은 0, physicalcompletion=null, production=HOLD, L4=false, whole-domain=false, actual-ODE=false를 유지한다. 각 원본 결과의 물리적 보류와 검토 의존성도 그대로다.
