# R3 | R118-C3T REI

In canonical q, ray number density g(q) affine on each cell. Moment N=∫g dq, V=∫(q-c)g dq, c arithmetic center; g=N/h+12 V(q-c)/h³. Under x=d q, local g_x=g_q/d; N invariant, U scales d. Overlap integral exact on each interval; same mesh identity, global N/U conserved for padded support. Shifted roundtrip is projection, not generally identity. Positivity of full affine density iff N>=0, |V|<=Nh/6; cone |V|<=Nh/2 weaker. Signed stock alone need not positive.
