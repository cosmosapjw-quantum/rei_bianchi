# SOURCE07 C8: bounded-order test and observed failure of naive adaptivity

Execution `OPENBLAS_NUM_THREADS=1 python3 research/source07_c8_adaptive_20261015/experiment.py` uses the frozen 2026-10-15 `source07_c8_quadrature_20261015/compare.py` physics, independent ages, and q=-0.01,0,+0.01. Method evaluates positive threshold-split Gauss-Legendre orders 4,8,16,32 and stops if relative successive order delta in nonzero HI,HeI,heat <1e-8. `HeII=0` in gas and must not be labeled tested.

**Observed:** all q cases choose order 32. Against independently integrated SciPy QUADPACK oracle the maximum checked error was ~5e-15, but order-32 elapsed ~0.022-0.027 s and the reference direct quad ~0.018-0.024 s. The first experiment's order-16 error was already ~1e-13, yet the n8-to-n16 successive gap triggered unnecessary refinement. Therefore this naive a-posteriori criterion is *inefficient* on this fixture; no speedup or full C8 compression admission. The successive difference is an estimator, not a guaranteed upper bound, and 32 was the maximum tested order. Never silently widen the physics tolerance, or claim 16 works under arbitrary source histories.

Reused literature: Friedrich et al. (2012) `https://arxiv.org/abs/1201.0602` warns about temperature step-size; Baumschlager et al. (2024) `https://www.aanda.org/articles/aa/full_html/2024/11/aa48164-23/aa48164-23.html` motivates reconstructing hardened spectra. Neither is direct evidence for this conservative order selector.
