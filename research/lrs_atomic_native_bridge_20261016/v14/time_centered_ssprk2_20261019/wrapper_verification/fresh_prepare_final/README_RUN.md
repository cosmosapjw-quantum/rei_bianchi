# Native SSPRK run receipt

This directory records PREPARED_ONLY. Numeric admission requires independent raw-data and source review. Prepare-only performs source reconstruction and compiler metadata checks; it does not compile, test, or run scientific cases. Every started native stage has command/stdout/stderr/exit/timing evidence, including failures. No network, installer, source normalization, automatic CFL subcycling, default/adaptive/checkpoint modification, or unconditional/stiff/full-EoR claim is part of this runner.
