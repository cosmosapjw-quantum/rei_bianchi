# Conditional 18-family nuclear sensitivity — implementation handoff

`nuclear_network.py` reads the 82 immutable isotope-quotient NPZ histories and the frozen `NUCLEAR_NETWORK_CONTRACT.json`. It evolves coupled T/neutron totals from exactly zero with a positive log-domain 2×2 frozen-hazard propagator, evaluates all 18 declared families and permitted reverse channels, and records log event fluxes and cumulative extents. It does not rerun cosmological backgrounds. The all-bare, instantaneous-thermalization assumption and passive six-isotope reservoirs define this sensitivity; there is no ionic state or gas-energy feedback prediction.

Run from this directory with `python3 -m unittest nuclear_network_tests -v` and, in a clean output directory containing the pinned inputs, `python3 nuclear_network.py --run`. The latter is one-shot and refuses to overwrite existing report/histories. `python3 nuclear_review_repair.py` derives authoritative endpoint T/neutron report fields from an existing saved NPZ once; `python3 nuclear_ledger_supplement.py` derives log coefficient tables and the separate Q/electron ledger without rerunning the network; `python3 nuclear_summary.py` produces the compact summary and two figures. Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0 and Matplotlib 3.10.8 were observed. No Git checkout exists in this snapshot, so no commit or push is claimed.

The successful bounded sweep used 82 original histories, nominal plus 2× source-grid reconstruction, 17.35 s wall and 17.32 s CPU. All finite cumulative forward and reverse channels had maximum 0.004844 dex difference, below the frozen 0.02 dex threshold; 4× was unnecessary. The maximum gross gain or loss of any initially present bulk isotope was 1.439×10⁻⁸⁰ of its initial inventory. Event-wise A and electron-completed Z are exact integer identities; reconstructed endpoint residuals divided by gross A turnover were 2.845×10⁻¹⁴ and 1.832×10⁻¹⁴. Six focused tests passed, including independent constant-source matrix exponentials and inherited DD Gamow-kernel parity.

The maximum surviving T is log₁₀(Y_T)=−103.8557710 and the maximum neutron total is log₁₀(Y_n)=−109.6589701. The maximum cumulative T births across all T-producing directions are log₁₀(C_T)=−95.4020480. Direct DDp dominates; secondary He3(n,p)T, D(n,γ)T and Li6(n,α)T cumulative births are approximately −117.1012, −123.7147 and −126.8547 dex. Because all-bare source coefficients use total isotope reservoirs that barely vary across the 82 atomic histories, endpoint T values vary by only 5.9×10⁻¹³ dex; the exact endpoint maximum case is a floating-point tie, not a physical ranking. Cumulative events can still vary with each proper-time history. The dominant p+D→He3+γ channel changes the He3/D/H bulk ledgers at about 10⁻⁸⁵ nuclei per baryon and does not dominate T births.

`NUCLEAR_NETWORK_HISTORIES.npz` stores case names, temperature/proper-time/density, log T/neutron stock, 18×2 directional log fluxes and cumulative extents. `NUCLEAR_NETWORK_REPORT.json` has all 82 case ledgers, coefficients/providers, Q by family, mass values and checks. `NUCLEAR_NETWORK_LOG_RATE_TABLE.npz` and `NUCLEAR_NETWORK_ENERGY_LEDGER.json` are derived coefficient and Q/beta-electron views. `NUCLEAR_NETWORK_SUMMARY.json` and the two PNGs provide a compact result. `NUCLEAR_NETWORK_RUN_RECEIPT.json` records commands, environment, resource measurements and the failed quadrature iteration.

A single physics-authorized numerical repair integrated the log-linear event flux exactly on each interval; the same all-finite-channel tolerance then passed. A separate C9 report-only repair preserved the before report in `review_repair/before/`: independently reconstructed T/neutron gain-minus-loss can cancel to a negative or zero floating-point result even though the positive propagated stock remains finite. `changes.net_abs` now uses authoritative propagated T/neutron stock, while `changes.event_reconstruction_net` and explicit discrepancies retain that reconstruction diagnostic. The maximum discrepancy is 11.31 relative to neutron stock but only 6.386×10⁻¹¹ relative to gross events. There were 37 negative and 29 zero reconstructed neutron net entries; none are interpreted as physical neutron absence.
