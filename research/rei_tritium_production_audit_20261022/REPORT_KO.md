# T=0 재검증과 핵반응 생성·소멸항 확장

기존 T=0은 물리적으로 계산된 핵반응 생성량이 아니다. 초기 T가 0이고 핵반응 생성항이 없는 원자 반응 파일럿에서, 출력 `lift()`가 T의 두 전하 상태를 0으로 채웠다. `CODE_PATH_AUDIT.json`에 실제 코드 경로와 기존 83개 결과의 읽기 전용 확인을 기록했다.

새 계산은 기존 82개 quotient 이력의 밀도·기체온도·고유시간을 재사용한다. 과거 우주론 적분, 완료된 검산, NCP 실행을 다시 돌리지 않았다. 핵종 수는 바리온당 비율 $Y_i=n_i/n_B$로 기록한다.

DII만 반응시키는 첫 DD 검증에서는 z=20→2 동안 직접 생성된 T의 최대 누적량이 $3.96127\times10^{-96}$, z=2의 잔존량이 약 $1.39375\times10^{-104}$이다. **모형 안에서 생성률은 양수이며, 정확한 0이 아니다.** 누적 생성과 현재 잔존량은 다르다. T의 12.312년 반감기는 우주론적 진화 시간에 비해 짧다.

확장 계산은 dossier의 핵반응 16개 표기를 13개 고유 반응군으로 묶고, D(α,γ)Li6, Li6(p,α)He3, Li6(n,α)T, Li7(p,α)He4, D(n,γ)T를 더한다. 총 18개 반응군의 생성·소멸 및 해당 역반응을 계산한다. 동일한 정·역반응 표기는 한 번만 센다. 두 β 붕괴를 포함한 물리적 방향은 34개다.

이 확장은 모든 핵을 bare nucleus로 취급하고 생성된 고속 입자가 즉시 열평형에 들어간다고 가정한 조건부 민감도 계산이다. 온도 100–10000 K에서의 실험적 검증이나 실제 고속 입자 감속을 대신하지 않는다. 하전입자 반응은 문헌의 저에너지 S 값을 상수로 연장하고, 중성자 반응은 명시적인 열적 1/v 모형을 사용한다. 자세한 범위는 `NUCLEAR_PROVIDER_INVENTORY.md`에 있다.

확장 모형에서 전체 경로를 합친 누적 T 생성량의 최댓값은 바리온당 약 $3.96234\times10^{-96}$이고, z=2의 잔존 T는 약 $1.39389\times10^{-104}$이다. 직접 D+D 생성이 우세하다. He3(n,p)T, D(n,γ)T, Li6(n,α)T도 포함했으며 각각의 누적 생성 로그는 별도 요약표에 저장했다. 잔존량의 case 간 차이는 반올림 수준이므로 그 최댓값의 case 이름을 물리적 순위로 해석하지 않는다. 누적 생성량은 고유시간 이력에 따라 달라질 수 있다.

외부 UV의 5–60 eV 지지구간은 핵 광분해의 MeV 문턱보다 낮으므로 해당 광반응은 이 외부 스펙트럼에 한해 정확히 0이다. 반면 흡열 역반응은 유한한 로그 생성률로 저장한다. 부동소수점 범위 아래로 내려간 값과 물리적 지지구간 때문에 0인 값은 별도 상태다.

첫 전체 반응망 계산은 극도로 좁은 흡열 역반응 구간에서 사다리꼴 적분의 수렴 조건을 통과하지 못했다. 실패 결과를 보존하고 구간별 로그 선형 생성률을 해석적으로 적분하도록 수정했다. 수정 계산의 모든 유한 반응 누적량에서 1×→2× 격자 차이는 최대 0.004843982 dex로, 원래 기준 0.02 dex 이내다. 수정 후 4× 재실행은 필요하지 않았다. 각 고정 핵종의 생성·소멸량을 합한 상대 변화의 최댓값은 약 $1.44\times10^{-80}$으로, 이 조건에서 passive reservoir 근사는 기준 이내다.

T/n의 잔존량은 직접 전파한 `log_T_n`이 기준이다. 훨씬 큰 누적 생성량과 소멸량을 빼면 n에 대해 음수나 0이 나타날 수 있으므로, 그 차이는 정밀도·재구성 진단값으로만 보존한다. T에서도 사건 기록의 차이와 직접 잔존량 사이 약 1.8%의 차이가 있어 숨기지 않고 표시한다. 이는 양의 직접 적분 잔존량을 음수로 해석할 이유가 아니다.

핵반응 Q는 사건별 별도 기록으로 남기며 기체 가열에 중복 가산하지 않는다. 새 T의 전하별 배분, 비열평형 감속, 기체·복사 에너지와의 결합 및 전체 production solver 승인은 이번 결과에 포함되지 않는다. 다음 실행 의존성과 공개·백업 상태는 `NEXT_DAG.json`, `HANDOFF.json`, `delivery/` 영수증을 따른다.
