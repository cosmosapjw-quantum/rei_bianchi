# Optional single wall-budget continuation

This capability is dormant unless GAUSS2_FINE terminates with exactly `TimeoutError: DECLARED_WALL_BUDGET_EXCEEDED`. It never resumes a solver minimum-step failure or domain failure. Its only possible use is one separately approved phase of at most 600 wall seconds in a new directory, after the terminal original artifacts have been backed up. No run is performed by this design task.

The original 5400-second phase remains immutable and reported as failed. A second phase reconstructs the same provider, fixed grid, scaling, event list, open-segment coefficient convention, and unchanged native `Coupled` RHS/Jacobian. It starts at `LAST_ACCEPTED.npz` inside its current segment. This necessarily introduces one extra BDF initialization; it does not restore BDF internal order/history. All completed segments and the prefix of the 129 prescribed sample epochs are retained without recomputation. State counters, prior domain flags, extrema, endpoint ledger maxima, RHS/Jacobian counts, and elapsed time accumulate across phases.

Before any native process starts, validation binds original first failure/result/history/last-state/as-run source files to an explicit terminal manifest, checks exact contiguous sample prefix, finite positive scales, state shape, gas/photon domain, event interval, and identity restrictions. Actual reconstruction additionally verifies source identities, grid, scales, initial state, and complete event schedule. The immutable original operator driver snapshot is retained; the continuation driver and validator receive distinct as-run snapshots and hashes. The original driver hash is **not** represented as the sole executed program.

A postprocess wrapper first verifies the full predecessor hash chain, then calls unchanged `postprocess.py` and extends its evidence bindings to the continuation files. The unmodified comparator is not continuation-aware. Comparison remains unsupported until an independent reviewer accepts the explicit continuation chain; the wrapper records this limitation rather than silently claiming identity equivalence.

Software tests use manufactured checkpoint artifacts only. Tests cover wrong failure, stale identity, missing/duplicate sample epochs, invalid last state, and a valid interior-segment continuation. They make no native, RHS, or scientific ODE calls. Production continuation is conditional and unexecuted.

Review additions: the exact resume state receives one output evaluation at the extra BDF boundary, persisted as `CONTINUATION_START.json` and included in combined endpoint E/N ledger maxima. The checkpoint validator itself is byte-bound during postprocessing. A separate actual-review-gated diagnostic comparator is available; it preserves all 24 frozen 65/129-epoch tests and always reports non-admission. Actual restart parity is untested.
